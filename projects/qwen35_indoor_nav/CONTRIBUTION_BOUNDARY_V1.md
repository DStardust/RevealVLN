# Q35N：贡献边界冻结 V1

日期：2026-09-09。研究准入文件，不是实验结论或投稿承诺。

## 1. 裁决与唯一保留的方向

`PASS_FOR_SPECIFIED_CLAIM`：下述**具体示范构造算子**值得进入数据可行性检验；此标记仅是有界的研究投资决定，不表示全球查重证明、贡献充分或科学验证通过。

原来宽泛的“观测约束教师生成示范，再 SFT”不作为原创贡献。其规划、教师约束和模仿基础已有直接先例。
本版本保留一个具体增量，不再继续平行发散：**带决策反转证书的成对导航示范构造**。
这是训练算法/数据算法候选，不是新的网络模块；普通交叉熵本身没有创新。

总体 G0 仍未通过：物理场景族、可用观测等价、任务真值与成本证书的可生成性未实测。算法实现、方法实验和训练仍暂停。
不允许把狭义预审 PASS 简写为“创新已证实、可以投 CVPR”。

## 2. 论文故事与模型定位

**让小型通用室内导航模型从示范中学会：什么时候值得通过行动取得证据，什么时候应直接前进。**

最终模型从 Qwen3.5-2B 通用预训练权重适配，统一语言目标寻找和路线指令导航；不是从零预训练 VLM。
先固定一种任务打通训练和闭环，再验证统一任务能力。预算反转是训练侧的可判别机制，不把整篇论文缩成“剩几步就多看一眼”。
自然分布、标准动作预算下仍必须受益；如果只在自造预算谜题上有效，则通用 VLN 故事不成立。

UAD 只继承候选随观测演化的问题意识；EgoCoT-Bench 只借鉴时间/实体/证据来源记录方式；VisualThink-VLA 明确归功，不重新声称证据路由或视觉思考原创。
不复用三状态标签、状态闭环说法或 benchmark 测试答案。家庭医疗养老是长期用途，不冒充已验证能力。

## 3. 冻结的具体算子

研究代号为描述性名称，不提前创建论文缩写。输入是一个有限候选池，不假定已有可用数据。

### 3.1 构造对象

每个场景族 f 包含：合法世界变体 W、同一可执行语言任务 g、预先声明的世界权重 p、共同因果前缀 h、有限原语集合 A，以及有限剩余行动预算集合 B。

- 世界差异尚未进入 h，但可以通过之后的正常 RGB 观测判断；不能只改目标 ID 或悄悄换任务答案。
- h 包含实际策略可访问的完整历史及预处理结果，不能只比较当前图像或 embedding。
- 策略输入为 x=(g, task_type, h, b)。剩余预算 b 对所有对照同样可见；否则同一输入附相反动作标签将形成不可能监督。
- 预算来自任务执行协议，不由隐藏目标距离或测试结果生成。不得用新预算协议的分数直接对比不同设置榜单。
- 先用受控确定性场景检验严格等价；该结果不自动适用于噪声环境或任意自然 RGB。

### 3.2 观测耦合回报计算：继承的规划基础

定义有限、完整到期的策略树族 T_b。不同世界中相同可用历史使用相同动作规则，只有获得可区分观测才能分支。

    Q_b(a) = min_{T in T_b : root(T)=a} sum_w p(w) J_w(T; b)

J 同时记录失败、真实动作成本和到期处理。到期不能接全知后缀；“观察”由普通运动原语实现，不是免费信息动作。
这一步属于已有部分观测规划。不得声称发明 Q、非前瞻约束、最优停止或观测分支树。

每个首动作提供 [L_b(a), U_b(a)]，界限只对声明的有限树族及代价有效。可用精确枚举获得相等上下界；近似搜索必须记录有效界限来源。
只有满足以下条件才保留唯一首动作标签 a*：

    U_b(a*) + delta < min_{a != a*} L_b(a),  delta > 0

并列、界限重叠、求解未完成的例子不强制标注，也不当负例。delta 和候选预算网格须在看结果前固定。
原版 DESPOT 的深度叶截断可能将上界设为下界，不能直接把该零间隙当作完整导航问题的最优性证书。

### 3.3 具体增量：成对提取，而不是均匀蒸馏

1. 对同一 f，在有限预算网格上计算上述证书；世界、先验、任务和原始前缀不随预算改变。
2. 提取预算相邻且被有效证书支持的首动作反转对；不假设最优动作对预算单调。没有反转就不伪造反转。
3. 保留的反转必须能在轨迹审计中关联到**任务相关证据的可获得性与成本**：一支先执行真实可区分观测的前缀，另一支选择其他行动；不能仅把更长路线换成更短路线称为信息获取。使用固定模板中的可验证任务谓词，不能由 VLM 打分定义真值。
4. 同时保留同预算下证据已足够、额外观察无用的匹配反例。每个可分析预算层必须包含相反的决策类型；否则预算捷径无法排除，该数据集不通过机制准入。
5. 将这些族整体编译成普通因果短动作示范，按场景族而非帧数计权，与常规导航示范混合训练同一策略。确切采样比例在独立实验协议中预注册；不把平衡采样或 CE 本身列为创新。

预算成对样本不是唯一训练数据，也不要求部署时输出“观察/前进”的新标签。运行期只输出固定运动原语和 STOP，无规划树、世界变体或特权教师。
任务证据审计不能从一般“图像变了”推导出来。若模板之外无法可靠定义，不得把有限模板贡献夸大成通用语义理解。

## 4. 最小纸面一致性检查

两种等概率隐藏世界，直接选左/右各需 2 步；选错不能在当前预算内补救。真实观察需 1 步，之后选对分支需 2 步。设 J=失败指示+0.01×已执行步数。

- b=2：直接行动期望成本 0.52；先观察后到期失败成本 1.02。
- b=3：先观察后成功成本 0.03；直接行动期望成本 0.52。

这说明输入包含预算时标签反转在数学上可以一致；不是实测结果，也不是新理论，正确 POMDP 规划器本来就能解。
还必须有 b=3 但观察不提供任务证据的反例，否则“预算充裕就观察”足以拟合。

## 5. 为什么给予狭义预审准入，而不是宣称贡献充分

已核对的最近算法中：DESPOT 解决规划但不定义这种成对训练集算子；GPO 耦合完整/部分观测下策略更新；CAST 改指令并生成动作；CFNBC 保持专家动作标签不变而按名义策略漂移选择修复样本；AdaTurn 随机预算并训练预算边界的强制回答。
这里实际改变的是**由任务回报界限支持的反转样本提取与配对监督**，不是只将这些方法换个导航名字。来源和代码证据见审查报告。

这为测试具体组合提供理由，但不证明它比“同一规划器的均匀示范”更有价值。最强审稿意见仍是：这只是昂贵的课程采样。该意见必须通过同预算对照解决，不能靠命名或附加模块回避。

贡献风险：中高；标签工程风险：高；部署额外机制成本：设计上低但尚未测量。
若同规划器均匀采样效果一样，原算法增量不成立，即使相对最短路 SFT 有正分也不能认定该贡献通过。

## 6. 必须预留的判别对照

| 对照 | 控制的解释 |
|---|---|
| 同 Qwen 普通合法导航 SFT | 底座是否能导航；不是唯一贡献对照 |
| 同物理世界池、同常规专家监督 | 仅增加环境多样性是否足够 |
| 同观测约束规划器、同求解与训练预算、均匀预算/示范采样 | 最关键：成对提取是否超过直接规划蒸馏 |
| 同池、相近不确定性/名义策略漂移筛选 | 是否只是 entropy 或已有反事实修复选样；适配控制不冒充完整 CFNBC 复现 |
| 去掉反转配对或去掉不值得观察的反例 | 收益是否来自配对机制，还是一味多观察 |
| 预算可见但不提供视觉证据的廉价诊断策略 | 能否只靠预算/模板捷径解决受控测试 |

所有对照共享策略输入、动作、数据访问、模型容量及训练更新预算；对标签生成分别报告仿真步数、规划节点、墙钟和失败率。不能把离线额外搜索当免费。
分组单位为原始 house/scene 及所有派生变体，不能将同族不同预算分到训练和测试。

主结局为独立场景完整 episode 的 SR，辅以 SPL、动作/时延/资源和失败类型。受控机制子集与自然分布分开。
两类语言任务、近期匹配强模型、独立场景泛化和完整消融是论文厚度条件，目前均未成立。

## 7. 冻结与重审边界

本文件冻结研究对象、贡献位置、最近方法差异和必需控制，不冻结未经测试的收益结论。
后续不因学习率、模型容量或工程实现细节反复泛搜。只有以下情况触发有界重审：

- 改变核心监督对象/采样算子/运行机制；
- 出现直接实现相同关键操作的新论文或实质遗漏；
- 数据接口迫使放弃物理反事实、回报证书或可用信息约束。

不能为了“已冻结”隐藏真正先例；也不能因为现有通用规划框架能表达该方法就自动否决具体数据算法。
