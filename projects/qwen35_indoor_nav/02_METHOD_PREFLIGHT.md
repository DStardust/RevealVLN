历史版本说明：本文保留初始候选和当时的证据缺口。GPO/DESPOT/CAST 的实现级比较现已完成于 [G0 审查 V1](reviews/Q35N_G0_CONTRIBUTION_REVIEW_V1.md)，新候选与狭义准入见 [贡献边界 V1](CONTRIBUTION_BOUNDARY_V1.md)。不要把本文旧“未读代码”状态当作当前进度。

## 1. 本版本保留与删除的选项

| 候选 | 标签与实现 | 主要风险 | 决定 |
|---|---|---|---|
| 候选集合 CE / 不确定时放宽标签 | 容易写损失；集合真值仍需来源 | 已有部分标签学习，且不自行监督信息获取动作 | 不作为核心 |
| 新视觉证据 token / 通道路由 / 记忆重加权 | 需额外感知或记忆机制 | VisualThink-VLA 及导航记忆工作直接接近 | 不作为核心 |
| 观测约束的示范构造，再训练小型导航策略 | 需合法仿真分支、自动成本和因果输入检查 | 已有 POMDP 规划、信息约束教师、模仿学习；具体增量待核验 | 唯一保留的立项审查候选 |

这里的“保留”只意味着值得完成定义，不表示已证明更快或更有效。

## 2. 最低可比较定义

部署输入 `x_t = (instruction, task_type, causal_RGB_history, action_history)`。
低层可选深度/里程计必须在协议中声明并给所有对照相同访问；不能从全局姿态中隐式生成学生特征。
输出为同一固定集合中的合法运动原语或 STOP；“观察”先由正常转向/移动实现，不增设能免费获得信息的动作。

训练侧候选操作：

1. 构造一组物理有效、任务定义一致的可重放场景变体。变体差异在某段策略输入历史中尚未暴露，且之后可以通过真实观测区分。
2. 不是分别为每个变体输出全知最短路，而是在分支规划时耦合它们：同一可用输入必须采用相同动作规则；只有观测真的区分了历史才允许分支。
3. 在有界动作候选和有限时域内比较动作树的任务成本，保留到达、失败和观测成本。不能用“信息增益大”替代任务回报。
4. 把选中的动作及其实际观测前缀变成示范，训练 Qwen 的导航动作策略；运行期不使用分支规划器或世界真值。

最低数学骨架：给定变体集合 W、预先声明的权重 p(w)、允许的有限策略树族 T，

`T* = argmin_{T in T} sum_w p(w) J_w(T)`，

约束：若两个树节点的实际策略输入 `x_t(w) = x_t(w')`，其动作分布相同。

`J` 的成功/失败/移动代价及终端处理必须事前冻结；到期未解决不许接上全知完美后缀冒充可实现收益。
只有对声明树族完成精确求解时才能称该有限族最优；截断搜索只能给近似解/上下界。

**以上骨架是已知部分观测决策和非前瞻约束，不是新的理论或损失。**
尚需核验的可能增量是：面向导航任务证据，如何以可审计、可扩展的构造与压缩规则产生这些示范，并在同预算下区别于直接使用现有规划器/教师。
本版本尚未指定一个足以支持此增量的原创算子，所以不签发 NOVELTY PASS。

## 3. 新定义补上的科学漏洞

- 不再将目标候选集合等同于动作标签。
- 不再仅删掉困难标签，导致模型仍学不到信息获取行为。
- 不能只改变目标 ID 而保持世界和语言不变：若新目标不满足语言，这是假数据，不是真实反事实。
- “没有见到目标”不等于不存在；历史已经见过的证据不会因当前遮挡而消失。
- 共享输入必须包含指令、传感器、过去动作和预处理结果；仅当前 RGB 相同或 embedding 接近不证明历史等价。
- 图像字节相同是受控实例中的严格证书；大多数真实高维观测不重复，因此受控等价收益不能直接外推自然场景。
- 对真实任务已经由指令消歧的情形，不强加多世界歧义，不强制额外观察。

## 4. 能区分机制、但不能证明新颖性的例子

设两种合法任务世界在当前输入下不可区分，先验各 1/2。直接选择左右分支的预期总成本为 7；
一次真实转向观察成本为 1，观察后到达成本为 4，合计 5；则耦合规划能偏好观察。
若观察成本改为 4，合计 8，则应直接行动。这里的成本只是预先给定的数学示意，不是实验结果。

集合标签、固定“总先观察”都不足以表达上述成本反转；但现有正确 POMDP 规划器能够表达。
因此该例只检查定义是否闭合，不能用作独立创新或正收益证据。

## 6. 下次立项审查的终点

固定一个实质增量算子，完成 GPO/DESPOT/CAST 的相关公式与可用代码映射，
说明其在同数据/同规划预算下改变什么、最简单替代为何不足、什么实验可以推翻它。

结果只能是：

- `PASS_FOR_SPECIFIED_CLAIM`：明确限定的增量值得实现检验，绝不是已保证 CVPR 接收或收益。
- `REFORMULATE`：差异存在但标签或机制不闭合；记录具体缺口。
- `NO_GO`：实际算子仅复现现有方法，或所需监督无法可靠取得；停止该候选，不靠换名字放行。

不把这里的策略树骨架当作“尚未检索的新算法”先做实验。
