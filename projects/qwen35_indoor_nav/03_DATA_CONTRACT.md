# 数据、监督与无人审核契约

2026-09-09 当前生产来源已选定并实地清点，见 [数据管线 V1](data_pipeline/v1/PIPELINE_ZH.md)：R2R-CE v1-3 train 的 10,819 个任务、3,603 条不同参考路线、61 个 MP3D 房屋。普通轨迹需真实回放生成 RGB/动作；机制族仍未验收。下方“未选定”和 THOR 优先是初始版本历史建议，不覆盖当前 Habitat/MP3D 方案。隔离、未知标签与证据约束继续适用。

版本提示：本文件为初始契约。当前机制数据以 [V3](MAINLINE_FREEZE_V3.md) 第 4 节为准：不同真实历史在同一物理状态汇合，不再要求 V1 的隐藏世界/预算反转。隔离、来源、未知标签和场景分组约束继续适用；数据源尚未选定。

状态：数据路线建议，未安装新仿真器、未生成样本、未验收标签。

## 1. 分开训练数据与机制数据

普通导航数据：合法的路线指令/目标任务及真实执行轨迹，用于普通 SFT 底座和等数据对照。
机制数据：可复算的场景变体族、观测前缀、动作分支成本与证据证书，用于验证新监督的独立增量。
前者可用现有真实场景接口，不代表后者已经可用。

最终不能只有模板任务：机制小试通过后，必须在自然语言路线和语言目标寻找上分别检验迁移。

## 2. 数据源的具体选择

现有 MP3D/Habitat：保留为普通导航数据和后续实景扫描环境评估候选，不假设静态扫描 mesh 可低成本变更物体关系。
B15 已记录语义图整幅为 0 的无效诊断；未获得指定版本修复验收前，不用于证据像素真值。

如果 02 的候选经新意审查值得继续，**机制数据优先评估可编辑的 AI2-THOR/ProcTHOR**，
原因是官方提供实例分割、对象元数据与场景/对象变化接口；不是因为它已在本项目就绪。
只允许在预算、许可证与最小环境验收计划确定后安装，不在本次文档工作中下载。

官方文档存在不等于正确变体已构造出来。尤其 `InitialRandomSpawn` 可能不移动对象，且移动后会重算 objectId；
需记录语义实体身份与仿真 runtime ID 的对应，不把跨变体 ID 字符串相同/不同直接当实体身份相同/不同。
参考：[环境观测](https://ai2thor.allenai.org/ithor/documentation/environment-state/)、[对象随机化](https://ai2thor.allenai.org/ithor/documentation/objects/domain-randomization/)。

## 3. 两份数据文件，不混合权限

`policy_input` 只包含：task_type、instruction、截止 t 的 RGB 引用、合法历史动作、明确允许的部署传感器。

`supervision_only` 包含：原始场景和变体族、状态种子、仿真实例标识、任务真值、证据时间戳、
可见像素/关系证书、分支成本、终止原因、示范目标、生成器版本、split group。
模型批处理采用字段白名单，不能直接把整个 JSON 拼进提示词。

最小字段：

`base_scene_id, variant_family_id, variant_id, task_spec_id, template_family_id,
prefix_id, prefix_end, input_preprocess_hash, observation_hashes, action_prefix_hash,
semantic_entity_id, runtime_object_id, witness_frames, certificate_status,
branch_horizon, branch_cost_components, terminal_status, target_provenance,
generator_version, source_license, split_group`。

内部元数据命名不进入模型输入；文件名、顺序、固定世界标签等侧信道也须检查。

## 4. 无人逐例审核如何做到有界可靠

1. 先定义结构化任务，使用模板生成等价语言；机器润色若不能证明语义保持，进入弱标签区，不做正式真值。
2. 核心谓词从真实实例、可验证几何/支撑关系开始；不让通用 LLM 决定药品功能、身份或医疗语义真值。
3. 证据支持需同时核对像素、实例映射、任务谓词与时间。几何可见不等于 Qwen 必然能识别。
4. 所有变体先稳定仿真状态，再重放；检查碰撞、目标合法性、可到达性、动作后观测与重复运行一致性。
5. 所有证书失败样本保留原因，不能悄悄丢弃到只剩有利样本。报告生成数量、有效率、分场景覆盖与失败类型。
6. 不确定标签保持 unknown；不自动当作 negative。未见实体/未枚举假设不可推定不存在。
7. 自动审核证明的是声明的程序契约，不是自然语言所有语义或真实家庭环境都已被证明。

## 5. 因果与反事实约束

- 不能把未来帧混入输入历史；未来结果可作为明确的离线训练目标，但不声称是 t 时已知事实。
- 同世界同前缀的分支须从同一快照恢复；跨变体的共享历史须检查全部输入而非只看当前图像。
- 目标类别、关系和指令必须在每个变体中一致成立；替换隐藏目标 ID 不是有效场景干预。
- 不用对象框投影越过墙壁判可见；不借全局 navmesh 隐式给学生过滤未来障碍。
- 受控数据的有限变体集合不是现实开放世界完整枚举，也不是 UAD 状态空间闭环证明。
- 如果无法可靠构造物理有效共享前缀，02 的机制数据门槛失败；不得改用合成文字对来冒充导航反事实。

## 6. 数据隔离

按 base scene/house、完整变体族分组；所有前缀、分支、同义改写整体同组。
另设模板/关系组合留出维度，不能仅靠场景分组就声称语言组合泛化。
明确哪些数据曾被 A/B/C/UAD 开发暴露；新目录不使旧场景自动“未见”。
EgoCoT-Bench 测试集、隐藏答案和与测试同视频的开发样本不进入本路线核心导航训练。
预训练数据未知时，仅声称实验开发划分未见，不声称 foundation-model 从未见过。
