# 完整方法、数据、工作流与验证流 V1

日期：2026-09-09。展开 [主线冻结 V3](MAINLINE_FREEZE_V3.md)，不改变主算法、不升级实验授权。当前事实以 [STATUS](STATUS.json) 为准。本文件是端到端规格，不是已运行的实验协议。

## 1. 产物、故事与创新边界

最终产物是一个可闭环输出导航动作的 VLN 模型。Qwen3.5-2B 是其预训练视觉语言底座，不是整个方法，也不是已具备导航能力的现成 checkpoint。

问题：当机器人看见相同当前位置时，不同的已执行任务历史可能要求不同后续行为。
方案：用物理合法的历史与续接交叉检查任务结果，监督导航实际使用的紧凑执行记忆，并联合学习动作。

论文核心是数据编译与共享记忆训练的联合算法；不是 BCE、循环记忆、自动机、预测状态表示或首次使用 Qwen。研究预审通过的范围和直接近邻见 [P1 裁决](reviews/Q35N_P1_PAPER_CORE_ADJUDICATION_V2/REPORT_ZH.md)。
没有新增已测导航收益。自然语言迁移、独立贡献和当代竞争力是必须取得的证据，不是名称自带的性质。

## 2. 功能模块与实现分包

| 功能模块 | 输入 → 输出 | 部署保留 | 贡献定位 |
|---|---|---|---|
| 自动数据编译器 | 任务程序、真实历史、合法续接 → 证书、Y、正确动作示范 | 否 | 联合算法的数据侧核心 |
| Qwen 视觉语言底座 | 指令、因果 RGB、动作历史表示 → 多模态特征 | 是 | 继承底座，做导航适配 |
| 有限执行记忆 | 旧记忆、当前输入 → 新记忆 | 是 | 与续接监督耦合；记忆结构本身不称原创 |
| 导航动作读出 | 当前特征、记忆 → 运动原语或 STOP | 是 | 必需导航接口，首版不单独造停止模块 |
| 续接结果读出器 | 因果记忆、指令、离线续接查询 → 任务结果概率 | 否 | 将编译结果监督到共享运行记忆 |

工程上只划分三个主要包：数据编译与校验；VLN 模型（底座、记忆、两个读出）；训练与闭环评估。目录名在实现节点确定，当前不创建算法代码。
首版不加入新地图、新 parser、世界模型、在线分支搜索、新 RL 或大教师常驻推理。并非禁止未来扩展，而是先识别一个机制的收益。

## 3. 数据处理全流程

### 3.1 先划分，再生成

登记每个源资产的物理路径、许可、版本与旧线暴露历史。按原始家屋划分 train/dev/confirm，家屋内全部轨迹、续接、任务改写、分支及变体同组。
模板/组合留出与场景留出分别定义，报告是否同时满足。预训练暴露未知，不声称 Qwen 从未见过对应场景。
数据源与模拟器仍待 P2 接口核验选定。V3 不要求移动物体，不自动沿用 V1 对可编辑场景的偏好。

### 3.2 两类数据

- 普通导航数据：有效指令/语言目标与合法正确示范，先训练会导航的底座，并在机制训练时维持正常导航覆盖。
- 机制数据：不同历史汇合到共同物理状态，再与不同合法续接、任务交叉；用于训练任务执行记忆与恢复动作。

普通自然指令可用于动作监督，不强行解析成未经审核的任务程序。严格续接标签先限定于从程序生成且语义可校验的语言。

### 3.3 构造真实历史族

指令例：先经过餐厅，再到卧室。历史 H1 已经过餐厅，H2 未经过餐厅，H3 在 H1 基础上有不改变任务完成情况的合法绕行。
它们确实运动到同一物理汇合状态；匹配朝向、对象/门状态、传感器和有效预算。近期共同尾段可相同，旧关键事件必须在当时的 RGB 中有可用证据。
尽量平衡历史长度、动作计数、场景外观和续接频率；不可能同时完全匹配时记录残差并做捷径诊断。
不能通过剪贴帧或瞬移把没有发生的前缀说成真实历史。

### 3.4 生成与检验续接

从汇合状态重放 C1（直接到卧室）、C2（经过餐厅再到卧室）等合法路线。检查器根据整条事件记录判定任务完成。
在允许重复经过餐厅、预算足够、其他约束均满足的示例任务中，H1+C1 成功、H2+C1 失败、H1+C2 与 H2+C2 均成功。
该例是定义说明，不是已测结果。改变任务程序后必须重算标签，不允许沿用。

    Y[i,k,j] = check(g_k, events(H_i) + events(C_j))

程序先定义正负语义，再生成语言。非法物理、未知语义、服务错误与真正任务失败分开；未知不充当负例。
不要将有限续接集合上结果一致的历史强制压成同一状态，也不声称状态空间闭合。

### 3.5 动作监督与负历史分开

有误的历史可以作为因果前缀，帮助模型学习恢复；其中错误动作不作为应模仿的正标签。
动作 CE 只施加于验证合格的正常或恢复示范位置，记录 action_loss_mask。负续接可训练结果读出器，但不因此获得正确动作标签。
恢复示范必须满足残余任务，而非只走到最终地点的最短路。多个动作同样合法时保留多样性；暂时相同首动作不是矛盾标签。

### 3.6 导出与质量报告

- policy_input：自然语言、截至当前的 RGB、实际动作历史；不含事件真值、场景 ID、坐标、未来查询或结果。
- supervision_only：任务程序、事件证书、共同状态检验、Y、续接查询、正确动作和 loss mask、分组及来源。
- 质量报告：尝试/合法/未知/拒绝数量，分场景覆盖，标签分布，真实重放一致性，所有失败原因。

路径名、文件顺序和 ID 不得成为隐含输入。无人逐例审核意味着机器契约核验，不等于自由自然语言或真实世界语义完全正确。

## 4. 训练流

### T0：运行接口与基础导航

先确定动作词表、视觉采样、记忆读写位置、精度、适配参数范围、模型与环境版本。优先评估参数高效微调的资源方案；是否 LoRA、作用层和 rank 尚未冻结，不冒充已验证接口。
先用普通合法示范进行导航 SFT，实测环境闭环。微型集过拟合只能证明优化/数据链路可运行，不能算泛化。

### T1：机制匹配训练

每个实验从同一已登记初始化开始；相同导航架构、轨迹池、视觉输入和优化预算，仅按对照修改监督。

1. 按原指令 I_k 和真实历史 H_i 顺序计算 m_{i,k}，较早历史只经声明的记忆传递。
2. 正确示范位置计算动作 CE；不对错误动作无差别做 CE。
3. 独立结果读出器读取 m_{i,k}、I_k、q_j，计算有效 Y 的 BCE。
4. 合并目标并更新导航适配参数、记忆与读出器；未来查询不进入策略前向或持久缓存。

    L = L_action + lambda * mean_valid_grouped BCE(R(m_{i,k}, I_k, q_j), Y[i,k,j])

q_j 描述离线实际续接的运动与可验证事件，没有检查器答案。记忆受指令条件化，换指令须重算。
按家屋族/历史族控制采样权重，避免大交叉矩阵让单一场景主导训练。普通与机制数据混合比例、lambda、训练预算在运行前固定。

### T2：梯度与因果信息流验收

首个机制小试采用短到可端到端展开的历史，让续接损失确实能更新关键旧事件的记忆写入；记录梯度/参数更新检查。
长序列扩展时另行固定截断反传或重算策略。若关键事件总在截断范围外且没有其他可学习路径，不能以“模型有记忆”掩盖监督无法训练历史写入的问题。
改变 q 不得改变固定参数下已经计算好的 m 或动作分布；改变较早关键事件应可影响 m。不得存在未登记的完整 KV 历史旁路。
通过这些检查只判工程正确性，不判算法独立收益。

## 5. 部署与闭环工作流

    导航指令 + 当前 RGB + 已执行动作 + 旧记忆
        → Qwen 导航模型更新记忆并输出动作/STOP
        → 环境或独立局部执行器执行
        → 新观测与实际执行反馈
        → 下一步导航决策

部署移除续接结果读出器、任务真值程序和未来查询，不在线搜索所有续接。不需要运行时人工标签。
机器人端运动未执行或被保护层打断时，不按计划动作假更新记忆。研究基准的 STOP 与机器人保护停机分开；机器人接口扩展不混入标准榜单策略输入。
路线导航与语言目标寻找最终使用同一 checkpoint 和明确任务接口，分别测量能力，不用多个任务专用模型冒充统一模型。

## 6. 实验对照矩阵

| ID | 数据与监督 | 主要识别问题 |
|---|---|---|
| M0 | 常规数据、动作监督、相同导航架构 | 普通底座能力；不是与完整法独立比较的唯一对照 |
| M1 | 完整轨迹池、仅正确动作监督 | 收益是否只是更多轨迹/恢复示范 |
| M2 | 与 M1 同池 + 高质量程序状态/已完成前缀监督 | 续接是否优于更简单的执行状态监督 |
| M3 | 同池 + 普通常规未来事件预测监督 | 收益是否只是通用辅助预测 |
| M4 | 同池 + 完整交叉续接结果监督 | 主方法 |
| A1/A2 | 去跨历史/跨任务关系，保留等量监督查询并登记采样 | 两种交叉关系是否各自必要 |

M1–M4 必须匹配底座、主干/记忆容量、数据访问、动作监督位置、传感器、优化预算和评估 episodes。辅助头参数与额外计算明示。
数据池收益与监督收益分开分析。先跑 M1/M2/M4 小试，主张有支持后补足 M3 和结构化消融，不能跳过它们直接宣称完整贡献。
结果查询-only、当前画面-only、历史长度/计数-only 是数据诊断，不是现代 VLN 强基线。后续另列近期同协议强方法，不以旧 VLFM 为唯一竞争力参照。

## 7. 验证流与通过含义

| 顺序 | 必须回答 | 证据/指标 | 不能据此声称 |
|---|---|---|---|
| P2 规格 | 接口、数据源、预算、数值协议能否落实 | 资产白名单、实际 API、协议和资源表 | 环境已就绪 |
| G1 数据验收 | 合法续接、可靠标签、可观察历史是否成立 | 重放、事件证书、unknown/失败率、独立数据诊断 | 导航正收益 |
| G2 模型验收 | 能否学动作、传递记忆且无未来泄漏 | 小集优化、梯度和输入扰动测试、闭环 smoke | 泛化或创新有效 |
| G3 首个机制 pilot | 同池监督是否产生独立效果 | M1/M2/M4 的家屋分组结果、完成率和恢复表现 | 正式确认或 SOTA |
| G4 独立确认 | 收益能否迁移到未用于调参的家屋 | 冻结协议，配对 episode、家屋簇区间、多种子 | 自然语言全任务通用 |
| G5 通用与自然迁移 | 是否只会程序模板，正常导航是否退化 | 自然路线 SR/SPL/nDTW/SDTW；同模型目标寻找 SR/SPL | 动态寻人或实机安全 |
| G6 贡献与竞争力 | 算法比强替代和近期方法有无优势 | M3/A1/A2、近期匹配对照、时延/显存/训练造数成本 | 保证论文接收 |
| G7 后续机器人验收 | 接口、实时性、执行误差与保护是否可用 | 目标硬件、控制接口、无人员风险环境测试 | 医疗决策或安全认证 |

G1–G7 是本文规划顺序名，不表示已注册可执行实验 ID；正式运行另行注册带版本的配置。各关失败保留原结果，不自动加模块。

### 7.1 指标与统计规则

受控程序机制任务的主结局是完整 episode 的程序满足率；公开自然导航任务按官方 SR 定义，不将二者混为一谈。
路线一致性、恢复成功、过早停止、动作/路径/墙钟成本为预注册次结局。恢复任务的受控错误类型、注入时点及权重对所有方法一致，并与正常分布分报。
成功率未退化才能讨论效率收益；否则同时报告成功—效率权衡，不用仅成功样本的快速度掩盖失败。
程序任务含必经事件时，不用单一终点最短路冒充满足任务的最优距离；官方 SPL 保持原协议。

在 dev pilot 后、confirm 结果可见前，冻结样本量、主对比、实用收益门槛 delta、正常任务非劣界限 epsilon、种子数和停止规则。当前数值待资源/方差估计，不以任意数值冒充已验收协议。
独立确认对主收益要求达到预注册实用门槛且家屋簇配对区间支持正向；正常任务按预注册非劣界限判断。多个主对比预设检验层级或多重比较处理。
报告全部纳入 episode、逐场景差异、区间、多种子与失败原因。服务故障单列；是否重跑及原记录如何纳入须预先规定，不事后删除。
旧线暴露、开发窥视和调参次数完整登记；没有干净家屋时如实限制泛化主张，不把新目录当新测试集。

## 8. 最快而不跳过科学条件的路线

先完成 P2；随后小规模真实数据验收 → 普通导航与信息流验收 → M1/M2/M4 独立家屋 pilot。
第一个值得投入的正反馈应是：合法且无泄漏的数据上，M4 对匹配强替代有闭环任务收益，并有跨家屋支持。仅读出器准确率提高是中间机制信号，不是该正结果。
若数据无法观测、简单状态监督不劣、收益只在一个模板或普通任务严重退化，停止相应主张并归因，不通过连续改变 confirm 集或追加模块追正号。
全套论文按 G4–G6 补齐；目前冻结的是研究方法与证据路线，不是已证实 CVPR 水平。

## 9. 尚需落实而非重新选题的事项

唯一首选数据/模拟器与许可；普通导航示范来源；动作尺度；视觉窗口和记忆槽数；Qwen 具体适配接口；训练规模、种子、超参数和预算；确认集与数值判据。
这些由 P2 及正式实验注册解决，不例行重新检索整个创新方向。若实际接口迫使改变核心算子，才版本化回到对应审查。

UAD 保留时间/证据意识，不复用不可靠状态标签；EgoCoT-Bench 可借鉴证据溯源的数据组织但需归功，不用测试视频/答案训练；VisualThink-VLA 的复用单独登记。
