# 真实单族捷径与标签稳健性审计

结论：**审计完成，保留单族接口验收；当前数据不能证明复杂执行记忆或交叉续接监督的独立收益。扩量前须处理动作计数捷径与强 M2 对照。** scientific_pass=false。

本审计只读取已封存 TV/sink V3 家族，未训练、未调用模型/仿真、未操作 GPU，也未读取或干预正在进行的 SFT。没有新增文献检索或人工评审。原封存 987 个文件的 SHA256 在审计前后全部通过且一致。

## 1. 离散特征是否足以拟合这 18 格

这里的“上限”是相同特征必须输出相同预测时，在已观察 18 格上逐组多数投票可达到的最大正确数；不是实际训练准确率，更不是泛化结果。

| 特征 | 分组数 | 拟合上限 |
|---|---:|---:|
| 任务 only | 2 | 12/18 |
| 语义 query only | 3 | 12/18 |
| 任务 + query | 6 | 14/18 |
| 当前 RGB / 两帧 RGB / 最近 8 动作 / 历史长度，各自单独 | 各 1 | 各 12/18 |
| 短窗全部信息 + 任务 + query | 6 | 14/18 |
| 全历史动作集合 + 任务 + query | 6 | 14/18 |
| 全历史动作计数 + 任务 + query | 18 | 18/18 |
| 全历史事件计数 + 任务 + query | 18 | 18/18 |
| 全历史事件集合 + 任务 + query | 12 | 18/18 |
| 因果 M2 程序状态 + 任务 + query | 12 | 18/18 |

同任务/query 的 4 个混合标签组确实要求某种历史信息；最近窗口和长度没有把差异泄漏出来。但这并不要求复杂时序表示，也不证明新训练算法优于现有状态监督。

重要捷径：所有历史长度均为 206，但动作直方图仍区分了三条历史：H_T 是 F54/L76/R76，H_K 是 F38/L96/R72，H_T_I 是 F100/L53/R53。只用动作计数查表就能把本族 18 格分开。这不是已证实跨族可用的导航算法，但意味着本族全拟合不足以证明模型识别了视觉事件。扩量时只做长度匹配仍不够。

事件集合来自离线语义像素 oracle，不是允许给策略的输入。在这个两事件任务实例中，它完全解释 Y，属于必须面对的简单替代；不得为了制造复杂性把该 oracle 故意削弱。

## 2. 强 M2 可否解释全部结果

从每个真实因果前缀的像素日志独立重算合并处状态，并与监督中 M2 状态逐格核对，18/18 一致。再以该状态、任务程序和 query 内有序事件执行独立检查器，18/18 与实际 Y 一致。

这是 oracle 标签充分性，而非部署 M2 已经解决视觉感知。M4 仍可能在学得的视觉记忆、优化、组合或导航上优于 M2，但必须通过同数据、同架构、同预算的实际比较，不能声称这里出现 M2 数学上无法表达的状态。

## 3. 像素阈值及数值规范化敏感性

事前冻结 192/224/256/288/320 五个阈值，保持同实例连续两帧。全部 27 条物理日志、每条两个任务均重算：

| 阈值 | 相对 256 的 Y 变化 / 54 | raw 边界替换与规范化 Y 差异 | 重建边界事件差异 |
|---|---:|---:|---:|
| 192 | 3 | 0 | 0 |
| 224 | 0 | 0 | 0 |
| 256 | 0 | 0 | 0 |
| 288 | 0 | 0 | 0 |
| 320 | 0 | 0 | 0 |

3 次变化实际是 **同一个 H_K/C0/g_T cell 的三个 seed 重复**，不是三个独立失败。C0 在第 233 步产生电视实例 135 的 [208,348] 像素对，192 阈值触发、256 不触发，令该格从 fail 变 pass。该事件位于续接，非历史或数值重建处。224–320 的 Y 稳定不代表逐时刻事件完全相同，完整差异计数保存在敏感性文件中。

数值边界比较只替换已存边界像素记录并重算该时刻、下一时刻与完整输出，不是重新执行未规范化全后缀。它支持“已存边界的事件稳定”，不证明任意物理扰动稳健。原始精确像素自然汇合失败仍保留；本审计没有改变 256 标签或重建规则。

## 4. 下一关要求

1. 普通 SFT 继续其冻结协议，无须因这些机制诊断停下。
2. 本族保持 interface_only，不拆 seed 或 cell 作 train/dev/test。
3. 多族小批量应保留所有尝试与失败；按房屋完整分组，动作计数 baseline 在独立组上测量，不能从单族查表上限推断跨族失败或成功。
4. 若目标是证明超越无序视觉记忆，应有合法且可观察的顺序区分证据；当前实例不足以支持该主张。不得临时重写标签或构造纸面假轨迹。
5. 机制首试必须保留强 M2 与事件集合基线，区分标签 oracle 和学得的视觉模型。M4 不优于它们时如实收口，而不以本族 18/18 冒充创新收益。
