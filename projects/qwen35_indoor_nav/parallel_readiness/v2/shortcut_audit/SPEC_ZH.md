# 单族 CPU 捷径与标签稳健性审计 V1（运行前冻结）

范围：只读 Q35N_G1R_FAMILY_CERTIFICATION_V1 的 18 个 cell 和 27 个回放日志；不训练、不仿真、不操作 GPU、不读取 SFT 结果。只写当前目录。

1. 开始与结束逐文件复核原 SHA256SUMS，并锁定本规格和审计代码。
2. 对 18 格等权计算离散特征分组纯度上限 sum(max(positive,negative))/18；这是经验拟合上限而非训练或泛化准确率。预注册：任务、语义 query、任务+query、当前 RGB、最近两帧 RGB、最近八动作、历史长度、以上短窗联合+任务+query；全历史动作计数/集合+任务+query；全历史合格事件集合/计数+任务+query。
3. 对强 M2 以合并边界的因果程序状态加语义 query 执行确定性 oracle，比较实际 Y。oracle 可读离线任务程序，不代表部署模型已经能识别视觉事件。报告任何全拟合的简单替代，不能把同 query 相反 Y 称为独立算法贡献。
4. 预注册阈值 192/224/256/288/320 像素，保持同实例连续两帧，逐回放重算事件和两任务 Y。只作敏感性诊断，不改原标签、生成器或准入阈值。分别替换数值重建边界为已存原始记录与规范化记录；比较边界及后一个时刻事件与整段 Y。该替换是已存像素日志的标签反事实诊断，不冒充未规范化整段物理重放。
5. 单测至少包含分组上限混合标签、阈值边界、不同实例不能串成 SEE2、缺失证据 unknown、时序约束、query 移除存储引用后不变、M2 oracle 正负。
6. 输出 result.json、分组证据、逐阈值诊断、单测和中文报告。scientific_pass=false；不把 seed 重复当独立样本，也不给置信区间/显著性。

停止：原封存哈希失配立即停止；显著捷径立即通知主 agent；不自行修改主线或扩量。
