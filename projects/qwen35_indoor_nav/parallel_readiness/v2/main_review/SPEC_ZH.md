# 并行主agent任务：公平对照与长历史接口预检

用户“和SFT多线并行”授权下的CPU准备节点。三条支线分别处理捷径审计、扩量协议、真实loader；主agent维护隔离分工并准备后续匹配实验。共享封存数据/源码只读，SFT协议和结果不读取或修改，无GPU/仿真/模型/下载。

本地脚本只解析现有真实trace、输出6条task×history的事件位置与截断梯度的计算图可达性诊断；不假装运行Qwen反向。梯度截断长度固定比较2/4/8/32/64/128/207，不据结果调已运行SFT。实际长历史梯度数值、显存与时延保持null。

输出后续M1/M2/M4与M3扩展对照的非可执行协议；训练预算、数据划分与SFT checkpoint未验收前不得启动。首族拟合与同房屋泛化/未见房屋泛化分开，不将数据捷径上限当训练准确率。
