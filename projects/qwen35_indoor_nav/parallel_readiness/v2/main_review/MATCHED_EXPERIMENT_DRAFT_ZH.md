# 后续匹配机制实验：不启动训练的准备协议

状态：NOT_EXECUTABLE；SFT仍由独立会话运行，本文件不改其数据或超参。最终样本、checkpoint哈希、数值预算、随机种子和停止规则须在获得新运行授权前一次性冻结。

## 必须回答的科学问题

交叉续接监督能否比同一数据上的动作监督、强任务状态监督，更有效地训练实际导航记忆，并带来独立任务的导航收益？不是能否拟合首个18格表，也不是是否优于一个没有记忆的弱模型。

| arm | 相同部分 | 唯一规定的差异 |
|---|---|---|
| M0 | 同一接收的普通SFT checkpoint | 只作为未经机制训练的冻结参考 |
| M1 | 同checkpoint、Qwen/LoRA/记忆/动作头、完整数据及动作CE owner | 无辅助损失 |
| M2 | 同M1 | 真实因果程序状态监督；所有合法时刻，不故意稀释/降质 |
| M4 | 同M1 | 分family/task/cell均匀的真实续接BCE，未知屏蔽 |
| M3（论文必需扩展） | 同M1 | 普通常规未来事件预测；区分一般预测性记忆收益 |

动作CE单独按unique owner采样，不能因3个query把轨迹权重乘3。不同task分别从零重放相同视觉历史，三个query可以共享同一个task-conditioned因果forward，不得互相写memory。所有arm均保留同等ordinary replay比例，正常导航退化单独报告。

## 先把接口验收做对

- 已通过G2仅是两步memory与synthetic query探针；真实族为207个prefix决策。SFT可选择短TBPTT用于工程验收，但不能将它自动当作M4已实现206步事件信用分配。
- 若在末4步之前detach memory，当前续接loss对更早激活的直接梯度被切断。共享参数仍可能间接学习，故不据静态图直接宣判学习不可能；应另做真实早期可见特征→memory→loss敏感性与梯度验收。
- G2 query Embedding(8)+mean是合成夹具。真实query含动作run、类别、顺序、重复数及STOP，不能直接复用8项词表或无序平均。独立的小序列编码器需正式接口/置换测试；其构造技术本身不列原创。
- 指令pooling、policy输入、reader输入和数据join字段分别白名单。未来query不得改变policy logits/memory/cache；没有额外KV/隐藏recurrent缓存绕过8槽memory。
- 本轮loader的CPU通过不等于上述Qwen运行检查通过，数值梯度、峰值显存、时延仍待测。

## 不把oracle等价当作学生已经学会

在当前两阶段任务中，准确的过去anchor状态与完整合法续接足以计算Y。M2 oracle能解释全部Y是预期强基线，不是泄漏本身，也不是学生必然能以相同样本效率学会。
但如果只复制这种布尔结构，并且简单历史计数/动作统计可替代执行记忆，数据不足以支持“理解时序”或贡献充分性。多族线必须依据捷径审计修正采样契约，而不是扩大相同容易表格。

不能只比较M4自有训练reader准确率与M1没有reader。离线诊断必须使用匹配的额外读出训练预算，或者明确把M2预测状态经同一合法query checker得到的概率作为强对照；oracle真状态不进入部署策略。

## 分开三个结论等级

1. 接口smoke：使用现有interface_only族验证代码与有限loss，不称科学正收益。
2. 多族fit/开发：同源house/完整几何族/全部措辞同组；禁止同族seed拆train/test。记录构造失败率、样本复用及多次配置尝试。
3. 独立确认：在事前冻结且模型训练未用的house/模板上测完整episode；当前20候选若全来自5个FIT_PILOT，只能作fit或seen-house研究，不宣称未见房屋泛化。

机制主指标应预定为完整程序满足率及错误后恢复；官方SR/SPL、nDTW/SDTW和普通路线不退化分开报告，不能用“到床且STOP”替代有序程序完成。比较配对episode和家屋聚合，不把18cell当18个独立环境。
