# 从立项到论文的验证顺序

状态：阶段规划草案，不是可执行实验协议；数值预算、样本量、阈值须在看新结果前另行冻结。

当前进度更新：论文主线已按 [冻结 V3](MAINLINE_FREEZE_V3.md) 选定，下一关为 P2 数据及实现规划。下文保留初始版本，不再执行 V1 的观察/预算机制；当前首试为历史敏感路线任务，关键对照见 V3 第 7 节。科学实验均未启动。

## 阶段 0：新意和监督可行性准入

唯一当前阶段。不跑新方法。

- 完成 02 的实际算子与最近方法映射；共同思想不自动否决，缺算子也不自动放行。
- 数据接口先做静态审查；后续若需运行环境验收，独立登记且仅判工程就绪，不判方法收益。
- 在纸面反例/边界情形中确认决策定义成立，包括“观察值得”“观察不值得”“指令已消歧”。
- 未清除核心近邻或标签缺口，不跳到大规模造数据和训练。

## 阶段 1：建立普通 Qwen 导航底座

只在准入与资源计划完成后执行。先单任务、固定动作与上下文接口，普通 SFT。
确认样本加载、动作合法性、闭环到达与停止能运行；不得把训练集成功当泛化。
该基线不需要承担原创性，也不因为使用新模型而被默认强于旧 VLN。
若底座不会导航，定位数据/优化/接口，不把新损失堆上去替代工程检查。

## 阶段 2：首个独立机制收益

主任务先固定一个静态语言目标导航设置，兼有证据已足够、需要补充、补充不划算的任务。
试验不要只筛“需要观察”的容易有利案例。专门富集的机制子集与自然任务分布分别报告。

最小对照：

- M0：普通 Qwen SFT，常规合法示范。
- M1：同一扩展数据池、相同训练 token/更新预算，但使用已知标准监督；隔离“只多了数据”的收益。
- M2：通过准入的候选算法，其余相同。
- M3：最接近的可复现实质算法/规划教师，对齐可见信息与数据生成预算；明确区分完整复现和机制控制。

对照可顺序执行以降低浪费，但具体顺序/停止条件预先登记；不能只报告跑到正数的组合。
如候选只改变数据构造而不改损失，应采用“同池不同标签”和“同预算不同池”两种对照，避免无法识别来源。

主结局：完整 episode 的 SR。关键次结局：SPL、过早 STOP、碰撞、动作数、导航墙钟时间、推理 p50/p95、峰值显存。
到达但不停、停止但未满足目标、超过动作预算、服务错误分别记录，不隐去失败。
路径跟随之后增加 nDTW/SDTW；目标指代定位指标只在相应协议定义时使用。

同时报告离线数据生成成本和训练成本，不能只展示部署省下的计算。
采用配对 episode 结果、scene/house 分组不确定性分析、逐场景和留一场景检查。
小 pilot 的正均值只能支持“值得扩大”，不自动支持稳定泛化。正式确认须有独立场景与事前样本规划。

## 阶段 3：检验通用性，而不是换任务后重新调到成功

在保留目标寻找能力的同时纳入路线指令，评估统一模型相对各任务基线是否退化。
路线与目标任务各自报告结果，不用一个综合平均掩盖某任务崩溃。
以场景、语言模板/组合、目标类别分别定义未见范围；受控场景变体正分后必须有自然环境数据上的迁移证据。
这里才讨论记忆长度、样本配比、容量扩展。新增模块须有实测瓶颈和新版本准入。

## 阶段 4：当代竞争力与投稿厚度

R2R-CE/RxR-CE 及合适的语言目标导航公开协议作为候选，最终按传感器和动作接口确定，不跨不兼容榜单拼分。
当代方法候选包括 AwareVLN、Progress-Think、SpaceVLN 等；各自任务、训练设置和代码可复现性不同，不能拿论文数字直接相减。
主对比至少包括匹配设置的近期强方法和我们自己同 backbone 的算法消融。
VLFM 2024、ETP-R1 只保留诊断价值，不能作为唯一“达到当前竞争力”的参照。

投稿证据至少包括：明确算法增量、跨场景闭环独立收益、两类任务的覆盖、强对照、完整成本、失败分析与数据许可/泄漏记录。
SR 接近强模型但资源更低可以是贡献线索；没有同协议成本测量不能宣称效率 SOTA。
未核实目标投稿年份规则前不固定截止日期，也不承诺接收。

## 停止与修订

- 数学机制不能优于最简单合理对照：停止该机制，不先增加模型容量。
- 标签不能复算：停止造数，解决接口或放弃依赖该标签的候选。
- 收益仅来自多数据/多计算：按真实来源描述，原算法贡献未成立。
- 只在单场景/单模板有效：记为局部结果，不能作泛化 PASS。
- 扩展计划不能覆盖实际 FAIL；所有重试使用新实验 ID `Q35N_G<gate>_<version>`。

本文无已测数值。下一步仍是阶段 0 的具体算子与近邻审查，不是启动阶段 1。
