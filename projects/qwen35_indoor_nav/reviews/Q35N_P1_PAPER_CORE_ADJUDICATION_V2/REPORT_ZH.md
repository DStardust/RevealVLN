# P1 论文主线裁决

日期：2026-09-09。机器顺序审查，非独立人工同行评审。

## 裁决

`GO_FOR_IMPLEMENTATION_PLANNING`：选定 [主线 V3](../../MAINLINE_FREEZE_V3.md) 的**交叉续接监督驱动执行记忆**，进入数据及实现规划。
`PASS_FOR_SPECIFIED_CLAIM` 表示具体联合算法具有可检验的操作差异，足以作研究投入选择；不是已经获得实验支持或已确认贡献充分。后者仍为 `UNTESTED`。
本轮不再将“会估计进度”单独作为创新，也不继续保留多个论文主方向。

## 顺序审查 A：现有证据支持到哪里

| 命题 | 判断 | 依据 / 最便宜检验 |
|---|---|---|
| 非 Markov 任务要求记住实际执行历史 | 有理论基础，不是新发现 | Reward Machines、PSR、自动机学习 |
| V2 的泛化状态 token 已足够新 | 否 | Progress-Think、Dual-Anchoring、Instruction-as-State 直接接近 |
| 续接结果能构成可区分的学习目标 | 在声明的有限任务上纸面成立 | 相同任务/查询而标签相反时，相同输入状态不能完美拟合 |
| 当前资产可合法生成这种数据 | 未测试 | P2 接口规格与后续重放验收 |
| 候选优于同数据进度标签辅助训练 | 未测试，核心证伪项 | 同架构、同数据、同优化预算对照 |
| 能提升所有 ObjectNav 情况 | 不支持全称主张 | 状态决定型成功条件可能与过去无关，V3 明确保留边界 |
| 可直接用于居家照护机器人 | 不支持 | 仅兼容导航分层接口，部署/安全/算力待验收 |

## 顺序审查 B：最小算法取舍

- 普通进度文字/自动机状态监督：标签可自动，但直接近邻多；作为强基线，不作为主创新。
- V1 预算反转示范：可保留历史候选，不承担完整主线，不再投入专属造数。
- **交叉续接任务结果监督＋实际运行记忆＋动作联合训练**：选择。只增加必要训练读出器，不能改为大世界模型或在线规划堆栈。

训练目标从“给过去起一个状态名称”变为“保留使相同未来路线产生不同任务结果的信息”。该直觉不是原创理论，选定的是其具体导航数据及训练实现。

## 最强否定解释与停止条件

**最强反对：只是预测状态表示在 VLN 上加一个辅助 BCE。**
回答不能是“我们用了 Qwen”。必须在相同数据上显示完整续接关系比普通进度状态/未来预测监督更能维持任务相关信息，并产生独立导航收益；否则模型贡献不成立。

**最强数据反对：只是多了真实恢复轨迹。**
必须比较同一轨迹池的动作 SFT、去交叉关系和完整监督；不能让对照只看少量干净轨迹。

**最强泛化反对：模板顺序小游戏。**
自然指令、原始家屋分组、历史长度/后缀捷径诊断和正常导航指标缺一不可；不得以单个程序任务正例判通用性。

**潜在信息泄漏：未来查询进入前缀。**
V3 将未来查询限制在训练读出器；模型记忆和动作前向必须先于查询且输入白名单隔离。未来监督允许，未来输入不允许。

**不能靠理论必胜替代实验。**
纸面可辨识不保证有限样本、有限记忆和优化能成功；在匹配实验失败时保留 FAIL，不自动扩大参数或追加模块。
