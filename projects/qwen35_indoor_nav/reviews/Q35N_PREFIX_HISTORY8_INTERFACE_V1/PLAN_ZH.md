# 全前缀8帧普通导航：GPU接口与成本诊断 V1

阶段A SR40前置工程诊断，非导航收益试验。本节点有界GPU1空闲卡一次启动，最多600秒、25GiB GPU、16GiB RSS、1GiB本节点输出；没有占位释放、其他进程信号、仿真动作、优化器step或保存新策略。只读现有Qwen2B/最佳4k和普通FIT数据；所有旧FAIL保留。

源码来自已通过真实CPU测试的ordinary_prefix_history8_v1/history.py,data.py和owned_process_r1.py。7类子进程退出/僵尸/身份变化/超时测试通过；Python缺少pidfd扩展的V1失败保留，R1用此x86_64 Linux的原生syscall434/424完成同等pidfd操作，不降级为未绑定PID信号。

唯一策略入口使用原实际FIT评测源码的模型加载/forward前缀，固定seed1209、batch1数值回归。实际旧32输入通过后才测新普通24输入（3来源各一路+最长一路，预选0/1/7/8/中间/最后）。32输入有/无hook共64前向；原2图与新8图各24单例前向；各4批×4样本前向反向=32样本，共144个策略决策前向、8次反向、0更新。没有新64FIT闭环或DEV/正式benchmark。原V12全量5487不一致仍保留，局部回归不是宣布其全部修复。

PASS仅指：原32logits max_abs<=1e-5/argmax相同；新接口输入合法且真实CPU离线/在线逐张量一致；两种输入的前向/反向有限、冻结主干无梯度、实际trainable最终逐位相同；资源清理回执正常。测量两种视图单步时延与训练微批成本，首批编译另列；不以训练样本accuracy认定导航提升，也不预设8帧必须和2帧logits相同。

下游普通训练须据测得的吞吐/显存冻结新对照预算、更新量、样本顺序、初始化/学习率；本诊断不得自动接续训练。完整1839 SR>=40门槛不变。
