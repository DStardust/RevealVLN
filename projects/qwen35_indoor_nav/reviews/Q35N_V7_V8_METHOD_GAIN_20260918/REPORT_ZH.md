# V7 实测结果与 V8 针对性修复

当前阶段：V7 完成 100 组四臂导航比较，V8 尚未运行。此文件随本轮真实执行更新，不是最终方法收益声明。

V7 的结果没有支持交叉续接监督带来导航收益：同进程原生 A 成功 20/100，精确状态监督 B2 为 18/100，交叉续接 Ours 为 14/100，仅动作训练 B1 为 16/100。没有采用或发布任何记忆策略。SR40、完整 1839 条新评测和真机部署均未完成。

## 已实际执行

- 使用 25 个已有真实 SEE2 候选族，按房屋固定为 6 屋 FIT、2 屋 CHECK。原资产的 `training_admission=false`、规范化接合和负控制缺项保留；SEE2 不改称到访房间。
- best4k 冻结编码器真实前向 24,598 次，缓存只由指令、因果 RGB 与已执行动作产生。未来查询只进入训练读出器。
- V7 的 B1、B2、Ours 各 3 个预定种子、每个 600 次更新，共 5,400 次真实优化更新。记忆写入、递归更新和动作读出参数均发生更新；编码器更新为 0。
- V7 导航采用预先固定的 seed1209 最终权重，100 组、每组原生/B2/Ours/B1 四臂，共 400 个完整 episode、81,425 次环境决策。原生 STOP 保护、500 决策预算和公共成功定义不变。
- 运行结束参数指纹未变，全部干预前原始输入、处理后输入、原生动作及 logits 一致，最大 logit 差为 0。所有成功都要求主动 STOP 且 geodesic distance <3m。

## 为什么修 V8

读取真实监督索引发现，FIT 的第一个动作监督在零基索引 156，即第 157 个决策；模型却从第一步使用记忆动作头。V7 的 B2/Ours/B1 在此前分别覆盖了原生动作 1,229/1,431/1,836 次。这是训练覆盖缺口；时间对齐核查没有发现标签错位。

这段没有记忆头新增 STOP，不能将其描述为早期错停问题。覆盖与失败的共现也不是因果证明。

V8 只给三种方法统一增加前 156 步的 KL(native policy || memory policy)，系数固定为 1，仍从 V7 相同初始化重新训练，使用同一轨迹、采样顺序、优化步数和种子。它不增加运行时阈值或年龄门控，不更改 STOP、查询编码、底模或输入历史。V7 和 V8 分开保存，不混合分母。

V8 代码已实现并通过 3 项真实 CPU 梯度/损失契约测试；对应闭环入口通过 6 项 CPU 测试。GPU 训练和导航结果尚待执行，CPU 测试不能当作模型收益。

## 方法主张的边界

V7 CHECK 上 Ours 相比 B2 的平均动作准确率变化为 -0.034 个百分点，交叉结果准确率也较低。核心相反历史对两行都判断正确的数量，B2 三种子为 10/48、6/48、10/48，Ours 为 6/48、0/48、2/48。非零跨步梯度证明了训练通路存在，没有证明模型学会保留关键历史。

精确状态对照用真实任务充分状态和确定性续接计算，全部 450 个已知标量标签通过组合核查。交叉结果没有比精确状态更多的信息；若简单替代同样有效，不能坚持 Ours 的优越性。

原始短窗重复率与包含记忆的完整策略输入重复率分开记录。记忆数值不断变化可以使完整输入不重复，本身不代表导航浪费减少。
