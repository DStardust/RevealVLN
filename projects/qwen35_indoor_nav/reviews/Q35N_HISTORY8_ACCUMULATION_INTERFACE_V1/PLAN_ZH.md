# 普通2/8帧配对训练的微批8/累积接口 V1

空闲GPU1一次，600秒、25GiB GPU、16GiB RSS、1GiB输出；不释放占位、无仿真/优化器更新。保留原入口32输入64次回归前向，再将action_query/exec_embed按已验证FP32 master转换并加载原best4k桥。共享训练runtime只读固定。

对每种历史模式的预选24普通输入中前8个，比较一次B8反向与两次B4累积（同8输入/标签/权重、相同全局归一化、无optimizer step）；2模式共32决策前向/6反向，合计96决策前向。事前数值门槛：B8与B4累积梯度总体相对L2<=0.05、余弦>=0.999；logits相对L2<=0.01且argmax一致；梯度有限、全部28组FP32 master最终逐位不变。B8峰值分配/预留<=25GiB。

通过后允许冻结microbatch8、每rank4次累积=32、三rank96的训练配置；不从接口通过自动宣称收益。失败保留，不放宽门槛，不自动训练。后续真正训练仍要单独通过CPU/IPC、初始绑定、预算与精确占位准入。此节点不是新科学机制，而是确定累积实现和显存可行。
