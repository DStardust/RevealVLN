# 当前200步完成后的基础导航分支

这是准备方案，不是已运行结果或自动启动权限。当前训练不中断、不改参数；完整终点评价后执行主agent裁决。

1. 若固定10路线拟合通过：先以同一模型做固定训练路线闭环工程检查，验证真实动作历史和STOP；再冻结全池多轮普通SFT及24-route开发评估。小集checkpoint不直接叫通用导航基座。
2. 若拟合仍明显单动作偏置：先按实际混淆矩阵、梯度与记忆尺度检查，不增加论文新模块。优先候选为只把old_slot/write_query/action_query的优化主参数改为FP32，VLM主干与注入/记忆仍BF16；这是数值优化修复而非新架构。改动必须验证初始logit/梯度路径，从同一initial重新做同10路线有界对照，不复用失败终点却声称公平对比。是否采用由终点证据决定。
3. 若多数动作已学会、只有STOP不足：单独测试事前固定的温和类别权重，保留完整episode，不只抽STOP帧。不要同时更换精度、学习率和标签权重。
4. 若离线小集很好但闭环失败：沿原指令参考路线生成实际偏离后的恢复示范，记录真实历史；不通过全局目标最短路替代路线指令。先做有界诊断再造数。

效率优先：FLA/causal_conv1d专用内核的独立版本验收，然后4卡数据并行；缓存本次无明显提速，不继续围绕缓存堆工程。当前基础模型没有用机制监督，所有基础修复需统一进入以后算法对照。

基础导航完成的最低证据应包含checkpoint可重载、完整动作接口、可报告的闭环到达并停止以及失败/碰撞统计。训练loss下降或仅拟合训练动作不够；正式泛化和CVPR贡献仍为独立后续关卡。
