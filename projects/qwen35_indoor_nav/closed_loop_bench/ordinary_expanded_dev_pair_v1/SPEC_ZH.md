# 扩量首段前后配对小闭环（开发诊断）

2026-09-12。标准基座建设，不是新算法/独立泛化确认。只读官方 R2R-CE v1-3 train 中原来预留的 INTERNAL_DEV 房屋，绝不纳入 FIT；所有输入/路线和两次检查点规则在运行前冻结。

选择：按与原生产相同的物理字段 SHA 去重，从五个 INTERNAL_DEV 房屋内按 SHA256(Q35N_EXPANDED_DEV_V1:physical_key) 排序，再逐屋轮转选 100 条；每条选择 episode_id 最小的一条原指令。容量不足的屋不重复采样，逐屋数量据实际索引记录。不是官方 val_unseen 的 100 条，更不是隐藏 test。

before 固定旧最终 checkpoint 51,301；after 固定 ordinary_expanded_v1 本次有界首段正常停止后的最终检查点，不按开发分数选 checkpoint。不是拿完整基准的 41,800 步冒充 before。训练收尾或回执不完整则不执行 after；不自动重试，不延长训练。

复用已审计完整基准的模型接口、两张 RGB/八动作窗口、原始指令、四个动作、0.25 m/15°、500 步、STOP 且严格小于 3 m、原 Habitat v0.1.7 SR/SPL 函数和精确 nDTW。独立 CPU PathFinder 核验 100 条实时起点距离；不使用离线缓存距离改分或当策略输入。八批/单条动作等价门槛复用，失败按原协议回退单条，不换模型。

GPU1 必须实测空闲（全部 C/G context 为空、显存小于 128 MiB）才启动，不释放任何占位/外部任务。每个模型最多 3,600 秒、50,000 个环境动作、28 GiB GPU、64 GiB CPU RSS、4 GiB输出；只清理自身新 session 的进程。模型权重只读、0 更新。baseline 和 after 串行，先 baseline，最长 4,800 秒等候训练自然收尾。任何故障写失败，不造缺失指标。

逐步独立核对策略动作和仿真动作、位置、距离、STOP、路径长度/碰撞；完整分母 100。配对报告 ΔSR/ΔSPL、逐屋差值、相同路线改善/退化以及到达后没停/未到就停、碰撞和动作数。事前开发性判断：ΔSR > 0 且 ΔSPL >= -0.02 为改善线索；不是统计显著、不是正式收益 PASS。无论小测结果如何都不自动开启下一段长训；结果仅供下一节点选择。五屋少样本不承诺增益。
