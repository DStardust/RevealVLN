|历史/任务|首次关键见证|最后见证|覆盖首次两帧证据至监督点的观察数|
|---|---:|---:|---:|

|H_B/task_B|14|71|236（13…248）|
|H_A_I/task_A|17|229|233（16…248）|

公共短窗只见247/248帧和240…247动作。177步是H_B最后见证距监督点的距离，不能据此
认定179步展开足以训练首次形成状态的写入。32步展开会错过H_B所有任务证据；若burn-in
已有已完成状态且detach，再拟合R不满足本关。保守全249观察展开尚未测显存/吞吐。

```mermaid
flowchart LR
  E[已观察关键RGB事件 e] --> W[第e步写入 Fθ]
  W --> M[可微 m_e]
  M --> U[逐步 Fθ 至 t]
  U --> T[运行记忆 m_t]
  T --> A[实际动作策略 Aθ]
  T --> R[训练读出 Rφ]
  Q[训练期合法续接 q] --> R
  R --> L[有效交叉结果损失]
```

反向必须存在 `L→R→m_t→F_t→…→m_e→F_e`；关键事件是输入，要求事件处写入调用的
激活/可训练路径获得梯度，不是要求修改原始RGB。共享θ在后面某步有梯度不能替代
关键事件处写入确实获梯度。

未来验收保留m_e.grad及事件处嵌入/写入输出的hook，记录其finite非零范数、对应监督
格、t/e、任务、图的截断点。对同一真实前缀移除该关键写入通路或在事件后detach应切断
该处VJP，即使后面共享参数仍有梯度。再检查动作loss读取m_t，辅助loss与运行memory
引用的是同一图中的tensor，不是另一个教师或离线缓存表示。

展开政策：完整前缀为首选待测规格；如需TBPTT，须逐族登记burn-in、detach与监督位置，
展开起点必须在关键事件的两帧证据之前。不能依赖未经训练的detached关键写入，并用
R拟合冒充记忆学习。所有匹配臂使用同一展开/截断和采样；activation checkpointing只有
在不改变梯度且记录额外重算成本时才可用。不得重算不完整旧历史后声称完整梯度。

同一任务/前缀多个q共享一次m的前向图，族内loss聚合后反向；跨族/episode不保留图或
memory。换任务重新encode_prefix；query改变不重新计算带query的memory。
部署使用inference_mode可以detach，但不能把它误用为训练递推。

当前：**NOT_TESTED_ON_MODEL**。CPU测试仅验证causal cutoff、精确状态和信息接口，没有
加载Qwen、计算autograd或验证上述梯度。需要更短且真实合法的机制族，或给本族明确的
展开资源预算后才能实际验收；本轮不自动造数或加载模型解决这一缺口。
