# B2 状态覆盖扩展首批

按最新用户澄清，贡献可来自具体算法、数据构造和实证发现，不要求基础思想完全新颖。旧新颖性报告保留；其扩量停止决定被本轮授权替代，但没有将 B2 现有方法创新改成已验证。

本批目标：为原 40 个历史族各生成一个当前终点不满足的对应条件，最多新增 160 条实际延长历史、480 次完整交叉执行、960 标签。它们依附原父族与原五个开发屋，不能算 40 个无关新族或新增测试房屋。仅原地真实转动和续接，不冒充移动导航恢复。

实现：collect.py 保留全部提案与失败，真实回放整个前缀及后缀；certify.py 用冻结 SEE2/STOP/500步定义复核；review.py 自动回读原始 RGB/语义数组并导出因果窗口、实际 PASS 动作教师、状态/查询监督。独立服务自行完成采集和 CPU 汇总，不训练模型。10 项 CPU 测试已通过，CPU 测试不是物理数据通过。

首次服务提交因工作树缺少默认 Python 路径失败，保留失败凭据；显式绑定已有项目 Python 后成功提交 02 服务。使用 GPU1，共享资源检查、3 小时累计上限、20 GiB 产物上限。GPU2–7占位未动。

停止后恢复必须先核实错误、源码和配置，以新的服务名运行同一 run-id 并加 --resume，不能把完整失败条件按分数重试。没有 Codex/API/终端依赖，但不承诺跨系统重启、OOM 或管理员停止。
