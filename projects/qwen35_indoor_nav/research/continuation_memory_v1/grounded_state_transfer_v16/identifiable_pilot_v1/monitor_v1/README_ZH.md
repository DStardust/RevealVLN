# Q35N 实时监控

服务已独立启动：`q35n-ident-monitor-20260921-02.service`。
页面每 5 秒自动刷新。关闭浏览器、终端或 Codex 不会停止实验。

## 打开页面

监控监听服务器本机 `127.0.0.1:18770`。

使用 VS Code Remote SSH：在「端口 / Ports」面板添加 **18770**，点击浏览器图标。

或在自己电脑上建立 SSH 转发（把最后一项换成平时登录服务器的地址或 SSH 别名）：

```bash
ssh -N -L 18770:127.0.0.1:18770 用户名@服务器地址
```

然后打开：<http://127.0.0.1:18770>。

## 页面内容

- 九模型训练状态、64 个完整配对组、576 次续接进度。
- 当前模型、条件、决策步数，GPU 显存和会话小时。
- 历史任务与历史无关对照分列，B1/B2/Ours 的 PASS/已完成及固定计划分母。
- Ours 对 B1/B2 的同条件同种子胜负；未知界、碰撞和预算耗尽。
- 输入/动作前缀审计、logits 逐位一致统计和最新阶段日志。
- 连接失败保留上次页面并明确提示，后台失败显示具体原因。

只有带完整组封存和模型状态封存的结果才进入分数；未封存尝试单列。新组首次读取时检查记录的日志 SHA。为避免反复读取大量轨迹，该监控缓存已核验的不可覆盖组；它不替代最终结果重算。

这是一间已暴露 DEV 房屋的受控 SEE2 历史任务。部分结果不能当作完整方法收益或普通 VLN-CE 泛化结论。
