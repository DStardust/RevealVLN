候选方案：Crossed Continuation Supervision for Task-Conditional Execution Memory

状态：正在执行针对性原型；尚无可宣称论文成立的正向证据。不能承诺发表。本文沿用既有交叉续接研究核心，不把传输修复、归一化或查询编码改动单独包装为创新。

具体命题是：在相同物理状态和当前短窗下，通过真实历史×合法续接×任务的结果监督，训练动作策略实际读取的有限记忆；在同一轨迹池、初始化和预算下，超过精确组合式任务状态监督的历史辨识与闭环恢复能力。

当前实测基础和反证必须同时保留：V10实际完成7200次轻量GPU更新、12份权重验证，旧写入到辅助监督具有211或310步的真实梯度连接。但离线动作准确率的改善被无记忆对照基本复现，当前自然闭环也低于原生。Ours原读出器在48个CHECK相反历史对上双方正确数为0/0/11；这些结果不支持方法优越性。

新增CPU探针完成9000次诊断头更新，原策略参数不变。冻结记忆并重训结果读出头后，FIT双方正确数从10/0/13升至50/49/48（每种子52对），CHECK升至9/11/12（48对）；然而CHECK全部216个标签的正确数从143/144/136降至124/110/118。整体泛化下降，不能以成对指标局部上升称为方法收益。精确状态探针表明部分旧信息可读，但随机未训练记忆也能拟合全部FIT对，因此训练拟合不能代替迁移证据。

下一项已经实现的修复只有训练查询读出：原查询采用从零训练的类型词表/GRU，CHECK含未训练的CATEGORY:tv_monitor等词。V11改用既有核验后缀中“是否立即STOP、是否STOP、后缀是否先见到任务锚点、末帧是否满足终点见证”四个语义量。它们与同任务下哪一条历史无关，450个标签可由这些量和精确前缀状态一致组合。前缀真值状态仅用于B2监督与离线审核，不能给Ours记忆或动作。未来语义仅进入训练读出器；部署不调用查询/程序检查器。四语义量仅覆盖当前SEE2任务，不能称为已经支持自然语言任意任务。

运行代码为model.py、losses.py、train.py与run_cpu.py。内存更新/动作接口继承contextual_readout_v10，只有训练result_head变化。CPU测试已验证初始运行参数逐位等于V10保存初始化、查询改动不影响记忆/动作、两臂真实更新和旧事件梯度。PROTOCOL.json固定B2/Ours、三个种子、每臂600次更新、原600次采样顺序和完整轨迹池。使用CPU FP32，不把与V10 GPU训练的版本差异称为单变量效果；主要比较本轮匹配的B2与Ours。

本轮最小正向信号同时要求：三个种子的Ours在CHECK历史相反对双方正确数均不低于B2、平均严格增加，而且全部标签平均准确率不下降。这只是已暴露两屋检查集的原型信号。通过后，仍要让正确记忆、错误历史供体、同任务状态供体在真正动作分叉和合法终止上产生相应区别；单纯读出改善不能进入论文结论。自然R2R评测继续作为退化检查，程序满足率与R2R官方SR分开。

最强证伪对照保持B2。已有精确检查器意味着结果标签不比完整程序状态包含更多信息；候选优势只能是学习方式、关系采样或迁移，而非“标签更丰富”“不用人工标注”。若匹配范围内B2更简单且稳定不差，则撤回交叉监督的模型优越性。B1、无记忆、普通未来预测及同状态记忆替换对照仍需在扩大结论前补齐。B2与Ours使用不同辅助头，实际可训练参数数目也须披露，不声称活动参数完全相等。

正式论文还缺：去除规范化/缺负控制问题后的真实回放证书；整族隔离的新场景与任务组合；策略实际使用语义记忆的干预证据；恢复收益与自然导航成本；同协议强方法比较。既有25族/8屋资产维持training_admission=false与debug用途，本次不会通过改名称将其变成正式数据。

一手来源于2026-09-19核查至摘要/版本入口，未声称复现代码：

- [RPSP Networks](https://arxiv.org/abs/1803.01489)已经把基于未来测试的递归状态与动作策略、预测辅助损失结合；因此“用未来预测训练记忆”本身不是新颖性。
- [Progress-Think](https://arxiv.org/abs/2511.17097)已经学习语义进度并用于导航策略；因此“比进度百分比更语义化”不足以构成区别。
- [Instruction-as-State](https://arxiv.org/abs/2604.18223)已经研究随感知状态变化的指令语义状态；任务条件状态本身不是首次提出。
- [WorldMemArena](https://arxiv.org/abs/2605.29341)已有多模态记忆写入、维护、检索与使用的分阶段诊断；仅把失败分阶段分析也不是本文独立贡献。

潜在贡献需要落在可物理执行的同状态交叉数据、该监督对部署记忆的独立作用，以及经过强简单替代和独立闭环检验的完整证据链上。本方案目前是可执行研究候选，不是“已经有结果可发文章”。
