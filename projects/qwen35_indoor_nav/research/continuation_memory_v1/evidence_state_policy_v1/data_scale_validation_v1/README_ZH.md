# 数据扩充匹配验证

此目录实现 OLD 与 EXPANDED 的同架构训练和真实闭环比较。两组使用原 MONOTONIC 模型、冻结 best4k、相同三个初始化、相同原始损失与普通动作样本顺序，每模型 1200 更新。新数据增加 816 父族/1491变体；扩充组共848父族/1550变体。固定旧FIT类别权重；在相同更新数下父族轮转，实际样本/步数曝光另记，不声称计算曝光完全相等。

四个已暴露开发留出屋保持训练隔离。计划256条件×6模型=1536续接；已有一个缺失物理变体，48槽位保持NOT_COLLECTED，实际可运行1488。主任务和task_T每组分别N=384，缺项保留识别界。正向信号须最坏未知分配差仍为正、至少3屋和2种子方向为正。统计单位有族/屋/种子相关性。无自然VLN、盲测泛化或论文贡献结论。
