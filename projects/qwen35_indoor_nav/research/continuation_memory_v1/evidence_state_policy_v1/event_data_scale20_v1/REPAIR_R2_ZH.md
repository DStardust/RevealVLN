# 生成任务运行修复 R2

停机原因是 NAS 全目录 du -sb 超过120秒，被同步调度器当作致命异常。停止时403个父族、638个变体、7656次完整交叉执行已验收；原有2–7卡占位已恢复。不是模型训练失败，也没有发现这批证书失败。

改为独立且身份核验的后台磁盘扫描，超时写 SCAN_TIMEOUT 并保留最后已测值及其时间；不谎报0或标作已超限。真正测得超300GiB仍停止，各屋数组写入17GiB硬上限保持。统计延迟时总盘量为陈旧观测，不能称实时精确计量。

两份停机遗留数组tmp将按原字节和SHA保存在 interrupted_writes_r2，绝不提升为合格数组。继续使用原收藏器，未闭合族完整重放；638份已有FAMILY/AUDIT元数据做不可变封存。旧源码锁不改，新增RUNTIME_AMENDMENT_R2记录新运行器SHA。历史失败报告另外保留；新运行状态继续显示在原监控网页。

入口：pipeline_r2.py --config PROTOCOL.json --run-id scale_001 --resume，以新独立服务名提交。
