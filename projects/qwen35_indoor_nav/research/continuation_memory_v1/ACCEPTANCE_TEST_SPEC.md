# 未来验收、强对照与停止

当前完成的14项CPU测试见 `CPU_TEST_RESULT.json`：真实loader→白名单、query/ID/pose
拒绝、任务变更拒用旧memory、前缀reset/连续性、实际动作与STOP、UNKNOWN、词表绑定、
真实18格精确状态、未来损坏不影响过去、缺证据mask、全族split、暴露边界和族均衡权重。
这些检查没有测试神经网络、物理重放、梯度、闭环或部署时延。

## 未来数据准入

每族必须有可核验源hash和实际重放证书、共享转移状态/短窗、真实可见关键事件、历史/任务
差异、登记的无关绕行不变对照、合法STOP。非法物理、服务失败、语义未知应为UNKNOWN
并单列失败分母，不伪造负例。检查语言/程序一致性，不能给未审核改写继承标签。
同pose不足；数值join若存在须保存raw/canonical差异及边界事件，按事前契约独立判断。
整个房屋、物理族、所有history/continuation/语言关联一起分组；分开登记已暴露数据。

## 未来机制准入

1. query-only、当前短窗＋I、长度/步数等捷径在核心相反标签成对单元上不可区分。不是要求
   全数据准确率都为50%；分别报告组基准和成对矛盾，不以随机负标签制造困难。
2. 关键事件写入的跨步梯度必须按 `GRADIENT_PATH_SPEC.md` 实测。检查同一运行memory
   的aux和action路径；query替换不影响之前的memory/action，任务变化重新计算memory。
3. 在同任务/物理状态/短窗的合法供体上，对照正确memory、不同任务状态供体、相同任务
   状态sham供体。看真实必要分叉及随后任务满足；清零损坏不能单独证明任务状态机制。
   整槽可能同时存空间信息，swap不是唯一变量解耦的证明。

## 未来比较准入

最先只做B1/B2/Ours的另行预注册机制筛选；本轮无此训练授权。三者共用初始state_dict、
实际轨迹池、动作owner、训练曝光、主干范围、展开、步数和选择预算。不得给Ours独有
恢复轨迹。原生B0是工程参照，不与新memory臂混作同架构因果对照。

确认性主要终点、最低有意义效果、非劣/等效边界、种子和预算目前为null，故不可启动。
不能事后把不显著当等效，也不能以没有显著超过B2却无限追加预算。在预注册预算内核心
强替代不被超过，停止本轮模型增量并回交。B3与关系消融仅在下一独立准入后展开。
去关系不可通过错配q/Y或删合法轨迹；匹配任务/续接/标签边际和有效调用。若相同三元组
已含全部关系，改batch顺序不是移除关系，无法隔离时记录混杂。

## 闭环与泛化

模板任务与自然任务、开发与独立测试、自然轨迹与受控扰动分别注册。
程序满足率≠R2R官方SR。报告合法STOP、首次错误后的恢复、错停/漏停以及适用的
SR/SPL/nDTW/SDTW；程序要求绕路时，效率参照须另说明，不能套最短目标SPL掩盖任务未完成。
扰动时间/形式冻结，所有臂承担同一实际扰动并写入历史和预算，不挑某臂失败的例子。

拒绝准入：只有R读出改善；策略未实际使用memory；B1已足够；B2不差且更简单；
只模板有效；自然导航退化；泄漏、不可观察或不合法数据。数值/资源无效为UNKNOWN。
发现具体直接先例则收窄或取消主张，不靠名字维持新颖。论文泛化须冻结后的新独立场景/
测试或合规隐藏测试；现有INTERNAL_DEV与1839公开结果不能换名成盲测。

部署成本必须含预处理、memory更新、action读出、p50/p95端到端时延、显存、持久槽字节、
视觉token和所有VLM调用。参考规格每决策2次主干前向，R删除不意味着memory免费。
G1基座可信、G2原工程SR40、G3方法证据是不同门；当前三者均未由本轮证明。
