# V12：冻结运动参数的状态依赖 STOP 行校准

2026-09-13；普通导航工程实验，不是 UAD 或新架构贡献。V11 完整100条 SR13%、SPL10.6373%、nDTW27.9148%，5赢13输，否决；不承接其权重。最佳4k为唯一比较基线（21% / 18.0169839234% / 36.5879700735%）。

失败审查：最佳模型26条曾进入目标范围但未正确STOP，另37条未到目标即STOP。统一STOP偏置在DEV已失败；同时改运动参数的V6/V8/V9/V11均丢失旧成功。证据支持分别检查终止预测，尚不能证明特征可泛化预测距离。只读诊断、拟合质量或FIT正号都不算用户所需结果。

压缩方案：保留现有2048维动作查询特征，仅拟合原4类动作头的STOP权重行和偏置（2049参数），其余全部逐张量不变。最强简单替代是旧全局偏置（已有负结果），不重复扫描偏置。该方案是普通的冻结表示线性二分类，既不宣称创新，也不加入模块/传感器。相同输入时三种运动logit保持逐位一致；STOP变更后的新闭环轨迹不保证相同。

数据：仅原最佳4k的FIT64/16屋实际轨迹，7225次原决策，按完整 instruction、最近2 RGB、最近8已执行动作去重。从已通过双重物理回放的V11 SUPERVISION_ONLY读取当前状态距离，交叉核对原记录前状态距离；target=有限距离<3m。未知运动教师不影响独立二值距离标签；同输入二值目标冲突整组隔离。特征输入文件只能含record_id、instruction、rgb_sha256、executed_actions；标签/房屋/距离/旧logits分文件，禁止输入模型。全部关联输入按原房屋分组，无DEV/CONFIRM输入。

固定算法（看特征/探针结果前登记）：排序16屋后random.Random(1209).shuffle，前4屋仅内层留出、另12屋训练。每条轨迹去重输入等权，再每屋内轨迹等权，最后房屋等权；不做正负类重加权。训练子集计算单一尺度 s=sqrt(weighted_mean(sum(h*h)))；x=h/s。原margin=z_STOP-max(z_F,z_L,z_R)。拟合残差 theta,b，目标 weighted BCEWithLogits(margin+x@theta+b,y)+0.001/2*(sum(theta²)+b²)。CPU float64 LBFGS，lr1，max_iter200/max_eval250，history_size50，tolerance_grad1e-7/tolerance_change1e-10，strong_wolfe，初值0。不扫描系数/种子/阈值，不挑中间迭代。最终STOP行=旧STOP行+theta/s，偏置=旧偏置+b，保存FP32。零阈值严格margin>0，四类原argmax并列规则不变。

内层廉价门槛：四个留出房屋合计，按上述房屋/轨迹权重，BCE降低；STOP precision、recall均不低于旧模型且F1严格提高；指标按保存FP32最终头计算。若不通过直接关闭本假设，不启动闭环、不调参。若通过，用全部16个FIT房屋同固定算法从零残差重拟合一次；只此最终模型。

后续门槛预登记：先同完整FIT64闭环，相对其原25% SR / 原SPL / 原nDTW，ΔSR>0、ΔSPL>=0、ΔnDTW>=-0.01，旧成功损失<=2条。通过才一次固定100 INTERNAL_DEV，相对最佳4k ΔSR>0、ΔSPL>=0、ΔnDTW>=-0.01。全部配对、逐屋、留一屋及源锁/动作审计保持。FIT受训练暴露，DEV反复暴露，任何结果都不是正式val_unseen或独立确认。

预算：GPU1仅确认空闲后一次最佳模型特征提取，batch1，最多6000次前向、1200秒、25GiB显存、16GiB RSS、1GiB新产物；无仿真动作、无GPU反向。CPU两个固定拟合各最多200 LBFGS迭代/250闭包调用，最多600秒。后续每次闭环单独冻结资源/运输锁（物理协议不变）；不释放其他GPU占位、不启动生产队列、不用付费API、不改冻结文件。模型特征提取先验证真实logits可重现原日志（所有去重输入原argmax一致，max_abs<=1e-5）；提取后参数摘要不变，资源只清理本次精确启动子进程。

验收：全因果输入重建/像素哈希、房屋隔离、标签一致性；CPU线性残差和折叠等价测试、非STOP参数逐位不变；封存代码/输入/最佳权重，先廉价门槛再决定是否具备闭环资格。实现/运输失败需保留并新版本修复，不能当假设否证。
