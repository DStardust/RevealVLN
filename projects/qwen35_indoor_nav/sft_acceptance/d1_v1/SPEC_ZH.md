# D0 + D1：小集可学性与双卡工程验收 V1

用户本轮批准执行上一轮建议步骤，并允许借用后部占位GPU、完成后恢复。本节点只写sft_acceptance/d1_v1；旧SFT、环境、权重、普通数据只读。不授权全量D2、机制训练、仿真或新导航评估。

固定选择：遍历原SPLIT.train顺序，每屋首次出现的两个不同job_id，每路线首条指令，共10路线；不读取dev进行选择。D0在旧terminal上，固定前两路线各前4决策，记录正常、每步零记忆、另一条路线指令/同时间图像置换的敏感性与模块梯度。置换是诊断，不是语义因果证明。不更新旧terminal。

D1从旧initial可训练参数开始，原Qwen3.5-2B、原LoRA、8槽循环记忆、四动作无权重CE、AdamW lr1e-4、eps1e-8、betas0.9/0.999、wd0.01、clip1不变。最多200次训练更新，TBPTT4；两rank各累积4chunk，按全局有效决策数归一化，最大32决策/update。固定rank交替分配路线，每rank按固定seed1109+rank循环洗牌5条路线，轨迹内连续、不跨rank传记忆；变长轨迹导致rank循环轮数可不同，保留实际暴露，不声称与原全池完全相同采样。

运行顺序：来源/CPU检查→GPU租借→NCCL及FP32 toy同步→加载模型/D0→恢复initial→真实BF16两chunk单卡参考与DDP梯度/一次诊断更新比较→恢复initial并丢弃诊断优化器→初始10路线全前缀评价→200训练更新→终点同10路线评价/重载核验。无中途dev选优或失败重启。真实等价探针为每rank一条独立路线前4步，总8决策；明确另外计入每rank单卡参考诊断更新1次和共享DDP诊断更新1次的计算，不混入200步终版。

等价关卡事前容限：FP32 toy梯度maxabs<=1e-6；真实BF16完整梯度relative L2<=0.10、cosine>=0.99；AdamW更新向量relative L2<=0.15（BF16舍入存在，不要求bitwise）。跨rank更新后参数要求逐位一致。任一失败停止，不运行D1。诊断参考采用同一8决策、相同chunk切断与全局归一化。

小集验收：终点train accuracy>=0.95、四类macro recall>=0.90、STOP precision>=0.90且recall>=0.90，全部满足才PASS。仅证明这10条训练路线可拟合，不是泛化、导航成功或算法收益。未达阈值按有界测试FAIL，不证明无限预算下不可学。评价保留CE、每类召回/混淆矩阵及动作频率常数基线。

资源：仅物理GPU5/6，各进程只可见自己一张卡，逻辑cuda:0，对应RANK0/1；不使用GPU3、不停止真实任务。仅核验后的占位可释放，保留其他既有小上下文。租借墙钟最多7200秒（两卡合计4GPU小时），总输出<=10GiB，worker合计RSS<=48GiB，每卡总占用<=28GiB，每rank前向token<=5M。模型OOM/非有限/通信错误停止不降配重试。无下载。launcher finally恢复两卡占位并核验；恢复受外部新任务阻挡则报告，绝不覆盖真实任务。

200更新terminal保存各rank优化器/RNG、自己的采样位置及分离后的循环记忆，只有终点日志与重载通过不等于中断精确续训已实测。固定代码与数据哈希在释放GPU前写入LOCK.json。基础SFT、DDP及任何后续数值修复都不作为原创贡献。
