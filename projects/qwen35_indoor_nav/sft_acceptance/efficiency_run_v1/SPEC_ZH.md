# 效率与小集实际训练 V1

用户最新要求推进、争取今天完成普通导航基座。批准范围先执行缓存/真实归约验收和原10路线200步小集训练，后续若通过再制定普通全池与闭环协议；本节点不自动扩量、不进行机制训练。旧D1更新相似性失败不改写。

输入与训练：复用d1_v1固定选择与种子、565决策、10路线、初始可训练checkpoint、原模型结构/AdamW/无权重CE/TBPTT4。两卡每rank4chunk、全局最多32决策/update、按有效决策数归一化，最多200训练更新；只有终点评价，不选dev最优。小集PASS仍需accuracy>=95%、macro recall>=90%、STOP precision/recall>=90%。本节点无新闭环、下载、环境改动或全池D2。失败不靠加步数通过。

## 新工程关卡的目的

旧D1比较独立计算的AdamW更新向量，0.202/0.163超0.15保持FAIL。本节点不是把阈值改成更大数，而是直接检验同一次反向产生的真实bucket是否被正确归约。先记录同卡重复前向/梯度变化；随后comm hook捕获每rank原始bucket，执行标准SUM/world_size，用捕获的原始张量独立CPU重算与实际结果比较；要求逐bucket误差<=2*dtype_eps*max(1,maxabs_expected)，同rank实际归约梯度一致、一次诊断更新后的参数SHA一致。不得把该通过称为旧单卡更新复刻通过。诊断优化器更新一次共享两rank，之后恢复initial丢弃优化器。

## 缓存与吞吐

从固定每rank首路线前4步做未缓存3次、冷缓存1次、热缓存3次forward+backward；无optimizer更新，所有真实耗时计入账本。只缓存processor输出和冻结视觉输出，不缓存语言隐藏状态/循环记忆。先逐tensor检查processor/视觉命中输出与首次计算完全一致；全chunk logits偏差<=max(1e-5,3倍同卡重复偏差)，梯度relative L2<=max(0.10,3倍同卡重复relative L2)，且同卡梯度重复误差<=0.10。记录模块梯度误差。匹配固定片段、不读dev做缓存选择。

只有两rank缓存正确且各自热缓存中位耗时比未缓存减少至少5%才共同启用，否则两rank一致不用缓存、照常原始计算。缓存没提速是工程结果，不是改变算法。任何非有限、输入/标签错误、归约错误停止，不自动重试。

首轮实际只借GPU5/6，不为短测试同时占四卡。资源上限同D1：租借7200秒、两卡累计4GPU小时、每卡总显存28GiB、总RSS48GiB、输出10GiB、每rank前向5Mtoken。仅释放已核验占位，保存身份并finally恢复。来源代码用只读import复用：d1_v1/worker.py的输出全局明确重绑定到本目录，仅调用Chunk/原模型构建/评估/训练等函数，不执行其main/equivalence；缓存源码efficiency_v1/frozen_cache.py只读。所有依赖哈希在租GPU前锁定。

训练基座完成需随后真实闭环证据，本节点通过仅能称小集可学性与训练工程通过，不能称通用导航完成或创新贡献成立。
