# V17：针对过早STOP的有界工程修复

V15、V16均已完整评测，不采用它们替代V13。本版不覆盖旧源码、权重、失败和逐轨迹结果。`DIAGNOSIS.json`记录两轮DEV100/公开unseen1839的首次分歧及跨会话对照；有原始pair路径和SHA可核对。

已确认：V15新增的156条unseen失败均以候选更早STOP作为首次动作分歧，69条获益也来自提前STOP，净损失87条。V16损失138条，其中135条首先发生运动分歧；虽拟合教师动作更好，却增加真实碰撞。两次运行共用的V15策略在1939条完整轨迹上位置、距离、动作计数、终态和指标一致。当前证据指向学习目标/读出修改造成策略退化，不能据此宣称底模容量不足或所有数据无效。

修改：从V13已保存权重出发，仅更新STOP行的2049个参数；运动行和底模逐位保留。仍使用相同640条已执行训练轨迹、37645个因果特征，新的64条恢复数据暂不加入，避免把额外数据贡献混入此次修复。

原目标按单步平均BCE，允许一条长轨迹的大多数负例掩盖少数致命误停，并对进入范围后的多个可STOP帧分别计正例。本版对每条真实轨迹，在第一次距离<3m的决策输入前，汇集去重完整输入的负例；用`softplus(logsumexp(m_negative))`重点压低这段路径上的过早STOP机会，首次合法STOP输入只计一个正例。未实际到达范围的轨迹不制造正例。这个函数是平滑风险替代损失，不是严格的闭环成功概率；贪心阈值、主动STOP、3m与500决策定义不变。

每屋、每物理轨迹等权；L2系数固定.001，残差以V13为锚点，特征归一化沿用V15训练输入权重。32/8训练屋诊断加40屋最终拟合，LBFGS各最多200迭代/250次损失计算；无DEV/TEST参数搜索。初始化与损失共同改变，不能分别声称独立因果增益。诊断屋可能在V13既有训练中暴露，不称其为盲测。
