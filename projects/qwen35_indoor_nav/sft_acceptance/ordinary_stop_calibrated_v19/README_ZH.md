# V19：按校准屋误停预算确定STOP截距

V15/V16完整结果与V17/V18失败保留。最新修复只保护较好的V13运动输出，仍是冻结底模的线性STOP读出工程，不是新架构或论文贡献。

固定640条物理轨迹来自40个训练屋。沿用既有划分，32屋用于一次拟合V18的固定终点/负例集合目标，8屋用于一次解析式STOP截距校准；不在这8屋重新拟合权重，不再用40屋refit替换模型。校准屋是选择数据，不能作为独立测试。底模和V13既有数据暴露均保留说明。

校准取每条轨迹所有真实范围外输入的最大STOP margin；参考风险预算是V13在这些相同校准轨迹上的任意误停率。对候选margin取加权顺序统计量，仅下调STOP bias，使校准误停不超过参考，固定1e-5处理数值边界。没有参数网格，没有读取DEV/unseen选择阈值。执行仍是原四类最终logits argmax，STOP和3m成功定义未改。

校准后仍须满足终点召回不低于参考90%、轨迹误停不高于参考，否则封存并停止。本轮不继续改权重或搜索阈值。通过后真实DEV100配对；SR提升且SPL不降才按预注册门槛运行一次公开unseen1839。已暴露数据不改名为盲测，有限开发收益不证明泛化。

上一轮结果说明：V17过度抑制STOP，真实终点预测从240/401降到9/401，已用FIT证据受控中止少量DEV执行；V18真实终点召回升到84.54%，但轨迹误停升到64.22%，被CPU门槛拦下，未运行GPU。本版是有记录的训练/校准修订，不把先前尝试抹除或当最终闭环改善。
