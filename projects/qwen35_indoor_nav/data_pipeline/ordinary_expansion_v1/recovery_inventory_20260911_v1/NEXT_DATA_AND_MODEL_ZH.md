# 接下来：数据先行，普通基座保留模型创新空间

2026-09-11。当前用户已将优先级明确为先做足够多的数据。普通导航基座可以承载模型创新；“基础能力建设”不等于禁止改架构。需要区分成熟方法复用、待检验的新算子和已经测出的贡献，不为凑创新添加没有证据的模块。

## 当前实际执行

已经启动本目录CPU回收任务q35n_envdrop_cpu_salvage_v1，14项单元检查通过。运行状态见run_001/PROGRESS.json；正在审核不等于已增加正式训练数量。此任务只读旧数据、重审像素/轨迹和双回放证书，最多两路CPU；没有新GPU造数、没有停止占位、没有修改当前训练或R2R-CE完整评测。

当前训练池固定为1394744条指令条件动作监督、5849条物理路线、17548条原始人工指令、51个FIT屋。旧EnvDrop滚动审核记录634414条动作，但原lane因单片墙钟预算关闭，没有最终合并，不能直接说当前训练已有203万。旧七条队列都已结束；其中部分正常排空，部分失败，不能按旧交接里的运行文字重复启动。

## 数据目标和执行顺序

1. 回收已有EnvDrop：完整片与中断片终态分别审核；旧隔离和旧失败保留；partial不当负样本，也不自动重试。全部复核完毕才发布新的独立TRAINING_INDEX.jsonl，不追加活动snapshot。
2. 对真正未尝试的原首波来源按约250路线小片恢复生产。新runtime/output/输入锁，真实首片强审后接续；GPU执行前另冻结具体资源预算、占位身份和恢复方式。不抢GPU1评测、GPU3/4/5训练，不恢复任何旧队列。
3. 依据实际合格产量从本地已取得的剩余EnvDrop来源继续扩源，补到至少3000000条去重有效指令条件动作。该数字是首档工程目标，不是模型必然学会导航的理论门槛；人工与官方合成语言分账，保留人工指令采样。
4. 同时准备独立的纠偏/终点困难样本规范：训练房屋里的真实走偏、撞墙无位移、错过门口和正确恢复；纠偏要与原指令剩余路线一致。此新池不是放宽原无碰撞专家示范的质量门槛，尚未生成或准入。

## 数据要给未来模型留什么

保留完整因果RGB/实际动作历史、动作前后真实观测、训练侧独立的执行与任务结果监督。不得把仿真位姿、目标距离、未来帧或检查器隐状态塞入部署输入。旧数据已有完整前缀，不只保存当前训练使用的两帧窗口。

普通基座的结构研究优先回答：如何让模型区分“发出了动作”与“动作产生了有效进展”，以及怎样利用早期路标避免长路线丢失进度。这些目前是研究问题，不是已确认的新模块。下一步需要明确算子、离线可核验标签、部署可用输入、最近方法与最强简单替代；普通门控、长历史或循环记忆本身不宣称原创。

数据齐备后采用“原结构/候选结构 × 原数据/扩展数据”的匹配对照，分别判断数据、结构和交互收益。DEV用于开发，CONFIRM用于事前冻结后的确认；官方val/test不进入造数训练池。普通导航SR/SPL和特殊任务严格完成率分别报告，特殊交叉续接主线及教师稿当前创新边界不变。

当前完成的是CPU回收实现与启动，不是已达到300万，也不是已经开始新的GPU扩产或模型创新训练。
