# 普通导航数据首批回放 V1（运行前冻结）

授权依据：用户在数据管线交付后明确要求“执行下一步”。本节点仅实现、生成并验收普通导航数据；不训练、不加载 Qwen、不运行机制 G1R，不覆盖 G1F 失败。

## 样本与来源

只读 P2 锁定 R2R-CE v1-3 train 和项目内 MP3D。先读取旧 SCENE_EXPOSURE 账本；账本中提及的房屋保守标记为 LEGACY_LEDGER_MENTION，不把提及自动升级成实际视觉暴露，也不将未命中称为未暴露。
另使用 B27 暴露审计中 actual_B_trajectory 的正面证据确定已执行房屋，不使用其 B-unexposed 列表作全局未见证明。
从有实际 B 轨迹证据且至少20条不同来源路线的房屋中按房屋 ID 字典序取前5个。每屋按数值 episode_id 排序取前20个不同物理路线，共100个固定候选。保留同路线的全部原指令映射，绝不从结果选任务。
这5个房屋冻结为 Q35N FIT_PILOT，整屋及其所有变体都不得进入本线 confirm；其余房屋保留 RESERVED_UNASSIGNED，未来划分另冻结。官方 val/test 内容不读取。本节点不创建或宣称 clean confirm。

## 编译及验收

- 使用已验收 Habitat-Sim0.1.7 独立环境，单空闲GPU2；不修改环境，不停止其他进程。
- RGB/semantic均224×224、HFOV90°、高1.25m；agent高1.5m、半径0.1m；F0.25m、L/R15°；physics off、sliding false。
- 初始 position/rotation 使用原始 episode，不 snap 改写起点。四元数源顺序xyzw显式转wxyz。状态初始化后检查与声明一致。
- 顺序跟随全部 reference_path，再到原 goal。每个目标点 geodesic<=0.35m 且 Euclidean<=0.35m 才可前进至下一路点；最终STOP同样<=0.35m。非有限距离拒绝。相比官方成功半径这是严格的示范生成条件，不冒充官方评估。
- greedy follower只用于离线动作生成。每次查询前后检查agent position/rotation未改变；真实轨迹只计实际sim.step，不计内部假想试探。
- 每段首次实际位置至对应reference waypoint的navmesh geodesic构成固定参考折线；实际移动点距离该段折线<=0.75m。记录逐路点误差、走过距离和最大偏移。不宣称稀疏路点约束能证明自然语言每个词的语义。
- 整条轨迹最多512个运动原语加1次STOP。任何碰撞、异常、缺帧、非法动作、超时/超长、黑帧均拒绝；不提供动作标签。零位移转向合法。
- 每个候选只编译一次，不调整阈值或替换失败候选。编译合格后，从相同原起点/种子重新实际执行全部动作；每帧RGB/semantic原始像素哈希与pose精确匹配方可认证。普通数据不要求语义任务标签，不将非零semantic视为语义真值验收。
- 原始原语动作+STOP写监督文件；指令/RGB引用写策略文件。取时刻t时只能读RGB[0:t+1]及actions[0:t]；路径ID/场景/坐标/未来帧/目标动作不拼提示词。读出器实现与测试随代码封存。
- PNG无损、内容寻址去重；仅导出认证通过路线，失败保留完整诊断日志。索引最后以原子替换发布；重启不覆盖已存在结果。

## 预注册判断与停止

100个尝试全部记账；生产管线pilot通过要求至少80个认证不同路线，且5个房屋各至少10个，所有导出样本完整性/因果loader测试通过。达不到则是产率/覆盖失败，已认证个体可保留但不能自动扩大。
这是有偏训练房屋的数据工程验收，不是模型SR/SPL、科学收益或全61屋产率估计。认证数量是实际通过数量，不保证100个都可用。
上限：100个候选，20GiB新增磁盘、16GiB单worker RAM、8GiBGPU、1小时worker墙钟。每个候选完成后落账；运行器异常只终止自己的worker并保存GPU清理记录。不因局部失败扩预算。
完成后停止，交付可用帧/路线/指令数、各屋通过率、失败原因、实际成本及下一批建议。后续1000条或训练无自动授权。
