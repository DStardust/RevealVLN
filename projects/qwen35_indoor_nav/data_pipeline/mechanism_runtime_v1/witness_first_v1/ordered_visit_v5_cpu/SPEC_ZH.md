# 顺序到访 V5：独立语义规格与 CPU 判定原型

2026-09-11。本节点实现上一多样性建议中的第一种自然到访程序，不改变冻结 see2 编译器、历史标签或当前训练。仅 CPU 逻辑验证，无 GPU 数据准入。它不属于本次教师稿的已验证新样本。

## 可检验目标

指令形式为“先到指定 A 附近，再到指定 B 附近停下”。到访与看见是不同事件；自然词面只在目标区域及物体指代都已核验后提供。不得把旧 see2 的标签直接继承过来。

预备到访判据：处于已认证目标区域，且到目标区域的 navmesh 测地距离不超过 1.0 米；该步及前一步都满足距离条件并看到同一合格实例，每帧至少256像素。此处距离指向预先冻结的可站立目标区域，不指向穿墙的物体中心。目标区域定义、姿态可见性及 A/B 区域分离仍需物理资产适配器核验。本 CPU 接口接收离线已测距离；没有对应真实证据时不允许造数。

区域分离认证须覆盖加入成功半径后的完整接受区域，而不只是两个目标点不同。若实际观察同时满足 A/B 到访判据，则区域契约不一致，返回 UNKNOWN。

顺序：A 的到访先完成，B 的到访须由 A 完成之后的两帧证据建立。起点已在 A 附近可以计为到访，但仍需两帧确认。此前看过或到过 B 不替代完成 A 后的 B 证据。终止：B 已按序到访，执行 STOP 时仍满足 B 的两帧到位与可见条件；不要求到访后一帧内立即 STOP。版本1不包含返回、重复到访或医疗操作。

轨迹必须完整、动作合法且无碰撞；资源中断、缺失距离、缺失图像证据、未认证目标区域等返回 UNKNOWN，不能作为负标签。合法完整轨迹违反顺序或停止条件才返回 FAIL。距离阈值及连续帧要求不依据未来产率调宽。

## 模型隔离与后续接入

zone 距离、实例编号、目标区域认证与程序状态仅供离线监督核验。模型仍只接收指令、实际 RGB 与执行动作，不附带“已到访 A”真值。后续需独立实现真实区域适配、typed query、强任务状态重算、动作 owner 与完整交叉关系，并冻结数据/房屋/预算再运行。

本节点只验证事件与顺序逻辑，不证明区域可观测性、自然语言泛化、真实标签正确率或导航收益。训练准入及运行准入均为 false。
