# 两类数据的生产方法与验收口径

普通分支已完成一个1,000路线批次；特殊分支已有一个独立质量通过的新族，仍在做跨屋重复生产验收。实时数量见本线 STATUS；本文记录配方和计数边界，不将运行中候选登记为合格数据。

## 普通导航示范

来源为合法 MP3D 场景中的官方 R2R-CE v1-3 train 与 RxR v0 guide 英语指令。所有路线按房屋分组，与特殊分支共用固定 FIT/INTERNAL_DEV/INTERNAL_CONFIRM；当前只生产 FIT。

1. 原始路线去重，保留对应的官方指令，不用自由生成文字替换标签；旧pilot已尝试路线排除。
2. Habitat 真实跟随路点，输出 RGB、实际动作、STOP；监督与策略可读字段分离。
3. 同动作第二次真实重放，逐帧核验 RGB、语义与pose；检查碰撞、路点误差、走廊偏差、长度和转向平移量。
4. 独立导出回读后提交不可变 shard 索引；失败与隔离记录保留，不放宽阈值凑数量。

本批实际计数：1,000条已处理路线；770条严格合格，覆盖51 FIT房屋；2,307条指令。56,018个不同路线上的决策，经原指令配对形成167,870个指令条件化决策记录。后者不是167,870个独立物理状态。另190条有重放证书但严格回读不合格而隔离，40条其他失败。20个shard索引哈希复核通过，无重复指令记录。

这证明声明的路线几何/回放/导出契约，不证明原自由语言每个词都经过人工语义审核，也不代表导航模型效果已经通过。基础300万有效监督记录仍是生产目标。

## 特殊交叉续接族

已采用的配方是先寻找真实可执行的片段，再组合与重新验证，而不是先凭语义名称假定一组路线存在。

1. 在固定 FIT 房屋采集真实去程、紧凑回返、语义实例证据和可汇合hub。保存全部动作、观测、事件与失败；仅完整合法片段进组件库。
2. 依据实际观测选择A/B事件回路、状态保持回路I及终点续接T；先冻结候选选择及来源锁。候选数量不是合格族数量。
3. 组合 H_A=a+i+a*(k−1)、H_A_I=a*k+i、H_B=b*j。匹配三段历史的F/L/R精确计数，并使用公共尾部。所需整圈转向必须实际证明不会触发A/B，不能只从角度和取模推断语义中性。
4. 使用有限、明确的结构化任务词面实现；仅规范已知词汇，不让LLM自由润色后自动当作真值。实际运行前冻结角色、指令、动作、源哈希与资源上限。
5. 实际重新执行组件与历史，核验完整agent/sensor汇合状态、双帧实例可见事件、碰撞和长度。原数值共同状态协议不变，禁止用任意teleport假造已走过的轨迹。
6. 运行3历史×3续接×2任务的18格检查，再冻结实际候选，进行3个预定seed共27次认证重放、54次任务求值。续接query只属于离线监督，不进入策略输入。
7. 关闭存储与预算、清理本进程后，由独立读回审计重算标签、M2强任务状态、历史反转/状态保持/任务差异、精确计数、因果白名单和来源链。全过程通过后才计质量合格族。

当前I对照准确名称是“已完成子目标后的回路放置变化”：H_A和H_A_I都含I，不声称一个没有I，更不声称I必然是无事件空间绕行。精确动作计数控制只排除了这一类捷径，不能称已排除所有模型捷径。

## 什么结果才算稳定生产的初步证据

事前门槛见 quality_cpu/batch_acceptance_v1/SPEC.json：至少两个固定批次，每批尝试至少3个不同hub且至少2个合格，总计至少6个合格独立hub、至少3个FIT房屋。同屋距离小于1米的hub合并；换seed、换角色名或重复导出不增加独立数量。

这是初步跨屋重复生产验收，不是大规模生成成功率的精确估计，更不是模型泛化、自然语言迁移或论文收益。资源中断保留为未闭合批，不冒充语义失败，也不把未提交日志尾部当已确认动作；恢复需新版本，不改原HEAD或补造STORE_CLOSE。

普通下一批须用独立分片、同一严格索引门槛。特殊下一批须先锁配置再执行，再核验质量与覆盖；当前不启动训练、不重新搜索论文方向、不修改主线冻结V3。
