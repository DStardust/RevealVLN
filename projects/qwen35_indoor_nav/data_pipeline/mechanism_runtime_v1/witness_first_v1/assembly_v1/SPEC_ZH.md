# Witness-first 真实组件拼接 V1

用户要求稳定生成目标特殊数据之前持续迭代；普通GPU5后台保留，旧GPU1紧凑批次按原停止规则完成。本节点新GPU2空闲非独占渲染，不停止外部进程/占位，不训练。

先从CPU锁定的真实trace证据筛A/B互斥、T-only前缀、中性公共尾和闭合组件，而不是固定一个metadata组合后反复碰运气。训练集内可观察证据驱动程序提案，是自动造数选择，不是未见评估或方法收益。角色(category,room)必须不同，不再沿用“终点与两个anchor房间均不同”的额外几何启发式，最终程序语义不变。

取已封存PROGRAM_CANDIDATES所有三闭合提案，按A/B净转向差、F数量差、最大组件长度、原索引排序固定首个；实际运行前冻结。已有I组件只是8动作转向，因此不得直接称移动绕行。运行必须另外生成真正>=2F的闭合中性移动回路，并验证A/B都没有被触发；其与I组件拼接再次真实验证。终点曾被看见但没有STOP不算任务完成；I历史不再额外禁止看见终点，仍禁止B，最终完整矩阵/事件/STOP检查不变。

三历史精确匹配F/L/R各动作数，不仅长度：不足F由实测中性移动回路填齐，净转向不相等则拒绝，不假定360旋转安全；剩余只用中性LR对补齐。H_A/H_B的中性绕行放在主要经历之前，H_A_I放在之后，三条action序列必须不同；这是无关移动绕行位置/时序变化的不变性，不声称“基线完全没有见过I”。所有组装历史重新实际回放、agent/sensor闭合<=1e-5、公共尾、18格/27重复重放/54求值和V4严格回读不变。任何数学拼接都只是候选，不当作物理证书。

更改的是数据发现与控制关系，不改变论文V3运行期记忆/续接训练算法。继承BCE、自动机、回路和匹配设计不宣称为新理论。即使首族通过，也不能说稳定跨屋、完整训练准入或科学收益。
