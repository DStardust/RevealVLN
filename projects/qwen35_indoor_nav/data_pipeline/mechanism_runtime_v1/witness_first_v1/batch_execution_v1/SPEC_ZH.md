# Witness bank 完整机制族批次 V1

从已完成房屋的真实bank做确定性候选选择，锁定所用源、动作、角色、任务、hub和匹配整数后才执行。不同(house,hub)优先，一hub只取排名第一的计数可解候选，不把角色重命名计独立族。

沿原checker，H_A=a+i+a*(k-1)、H_A_I=a*k+i、H_B=b*j，k>=2。只有F数、净L-R数相同者可入选，末端仅LR对补齐，三history动作计数精确相同且长度<=512（含8步公共尾）。a/b/i均从完整实际回路提案而来，实际再验证后才能接入全矩阵。i是已完成A后的回路放置变化，明确不声称H_A没有I、不声称无事件空间绕行。

原18格、27seed实际回放/54求值、双帧实例事件、完整pose/两个sensor汇合与原V4查询/loader约束不改。仅candidate_fit_pool导出，training_admission保持false直至独立数据审查；模型训练和导航收益未运行。每批固定候选与输入锁在动作前保存，失败/截断各自留账，不自动换候选。

每批最多3个不同hub候选、GPU1或2、监督3900秒、工厂3600秒/60000动作；每候选发现1000秒/15000动作、认证1500秒/20000动作；content6GiB/总8GiB（监督7GiB提前停）、RAM8GiB。只用已核实低负载GPU、仅清自身，不触碰外部占位或任务。可两张卡独立目录并行，不共享可写结果。初步工程稳定批次门槛另由quality batch spec预先冻结，不将单族或CPU候选升格。
