# Witness-first：已有真实轨迹的角色兼容性

结论：已有证据支持从实际可见轨迹中选择 A/B，值得按组件拼接验证；**没有新物理族或训练准入 PASS**。

本次固定读取 370 条完整 trace（V1 加 compact V2 的只读快照，V2 非终态）。仅三个已开发 FIT 房屋；后续出现的文件不进入此快照。每个文件须完整、内容稳定、自身 trace_hash 正确；没有读取 heldout、运行仿真或修改原数据。

## 规则及实现

使用封存 compiler 的真实阈值：同一实例在两个连续、证据完整的帧中均至少 256 像素。所有实例先算事件，再按 raw/mpcat40/room 映射到原有限词表；不能由两个不同实例拼成 see2。实际 Compiler.atoms 在 370 条 trace 上逐角色结果与本筛选器完全一致。

同起点采用完整 agent/sensor 初始 pose 的精确键。A/B 必须各有一个因果前缀见到自身而尚未见到另一角色；共同 LRLRLRLR 公共尾不得触发 A/B/T。闭合组件还需实际 trace 的 agent、RGB、semantic 末端位姿距起点均不超过 1e-5，长度不超过 504。仅有前缀见证的记录不称闭合回路。

与旧 metadata planner 的明确区别：不再硬要求 A/B/T 分属三个房间；只要求各角色的 `(mpcat40, room)` 组合不同，防止只换 raw 名字而 query 语义相同。旧三个房间筛选是构造启发式，不是 V3 主线要求；下面提供其可选统计，未据结果改原排序。

## 实际结果

- 166 个同起点 A/B 互斥角色对：17DRP5sb8fy 有 85，1pXnuDYAj8r 有 81；1LXtFkjw3qL 暂无。这是角色/状态组合，不是 166 个独立数据族。
- 76 对具有中性公共尾；23 对具有已有实际 A/B 闭合回路。
- 679 个四角色前缀兼容程序；固定排序导出前 100 个供主 agent 审查。
- 7 个程序同时有 A/B/I 闭合 trace，但都集中在一个房屋、两个起点；其中 I 均为 8 步纯转向公共尾，**不能称为有意义的移动绕行**。

最接近可拼接验证的一个组件组：17DRP5sb8fy 起点 `[-6.421979904174805, 0.07244700193405151, -1.3795599937438965]`、yaw 0；A 为 familyroom/lounge coffee table（158），B 为 living room coffee table（132），T 为 living room couch（130），I 为 bedroom bed（5）。compact V2 的 trace 142 为 A 的 58 步闭合回路，136 为 B 的 54 步闭合回路；134 的前 1 步提供 T-only 前缀，132 提供中性公共尾。完整路径及 SHA256 在 PROGRAM_CANDIDATES.json。这是组件见证，不是18格认证。

## 额外过滤，不修改已导出候选

| 检查 | 全部 679 程序中的数量 |
|---|---:|
| A/B/I 都已有实际闭合回路 | 7 |
| I 闭合回路含至少 2 个 F | 87 |
| I 闭合动作与 A/B 两者不同，且三回路齐全 | 7 |
| A/B/T 分属三个房间（旧启发式） | 196 |
| 公共 LRLRLRLR 不触发 A/B/T | 679 |
| 三闭合回路＋I 至少2F＋不同动作＋公共尾中性 | **0** |

87 个有移动 I 的程序尚缺某个现有 A/B 闭合组件，不能把它们与其他起点的见证混拼。所有额外过滤明细在 OPTIONAL_FILTERS.json；不从“0 个全部已有组件”推断新路线无法构造。

## 主 agent 下一步

先对上述真实组件做新的独立拼接/等长控制与18格认证，不重跑 metadata 任意配对；若缺有意义 I 回路，明确新构造该组件。必须重新验证组合后的碰撞、事件、公共尾、相同动作计数、共同 join、三个合法 continuation、三 seed 重放及捷径控制。前缀 witness 不证明插入 STOP 后的完整任务、拼接可执行或反事实矩阵；这些仍全部未证。

该选择是探索性训练数据生产，不是未见场景效能实验；一个房屋的组件可用性不能支持泛化或创新收益。后续跨屋 witness bank 需独立版本与原场景分组。
