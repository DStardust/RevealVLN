# 本轮问答：论文主体、既有工作的关系与准入边界

本文解释 MAINLINE_FREEZE_V3，不修改已冻结的算法、当前P0候选或实验协议，不签发新的创新PASS。

## 论文主体

最终交付主体是基于通用预训练Qwen3.5-2B训练的室内VLN，而非在现有完整VLN上追加补丁，也不是只输出记忆分类结果的组件。普通目标导航、自然语言路线导航与历史敏感的多阶段执行应由共享策略支持；这些能力需要各自数据和评估，不因为同一网络接口就自动成立。

创新核心仍是：真实历史×实际续接×任务的交叉执行关系，与运行期实际使用的执行记忆联合训练。训练读出器根据因果记忆和离线续接查询预测任务结果；未来查询不进入策略或其记忆，部署去掉读出器，保留导航记忆。

论文不能预先称为已经具备通用室内能力。当前P0只验固定模板数据构造；自然语言迁移、独立场景闭环导航与模型独立收益仍未成立。语义谓词当前是可见事件，不是实际进入房间、精确到达物体或医疗任务完成。

## 与UAD和EgoCoT-Bench的关系

- UAD保留历史证据会改变后续任务决策的科学直觉，不沿用人工U/A/D标签或状态空间闭环主张。有限续接集合的结果相同，不证明全局充分状态或完整世界模型。
- EgoCoT-Bench借鉴证据与真实帧、稳定实例、时间位置和可追溯数据组织的联系。引用既有贡献，不把证据绑定本身作为新的算法，不复用测试答案或同视频开发数据。当前产物不能未经记录就称为复用了其代码/数据。
- 同组VisualThink-VLA的视觉推理/表示技术属于需归功与区分的基础，不能将证据token或通道路由改名作为本论文主创新。

## CVPR贡献的实际门槛

当前创新状态来自P1的PASS_FOR_SPECIFIED_CLAIM，仅为研究准入；贡献充分性和导航收益未验证。不存在由一次机器审查给出的零风险证书。冻结后不例行泛搜，但直接同构先例、核心变更或实质遗漏仍必须处理。

必须分别证明：

1. 具体数据算子/训练通路相对近邻的差异，而非Qwen版本、BCE、循环记忆或自动机理论的新颖性。
2. 同模型/同数据/同预算优于动作监督、强任务状态监督、事件集合和常规未来预测，排除数量、身份、动作计数与泄漏。
3. 历史敏感任务的收益能迁移到自然指令和独立场景；同时正常目标/路线导航不退化，成本实测且对照匹配。

当前三历史模板可能由过去事件是否发生解释，不足以宣称顺序推理。若最简单强对照同样有效，不能仅用故事包装维持贡献主张。P0构造率不是算法收益，也不是CVPR投稿门槛本身。

## 居家医疗养老机器人的边界

本线可以作为系统的高层语言导航研究底座，向局部规划与运动控制输出导航决策；不等于轮足机器人完整自主系统。局部避障、控制、动态人群、找人/跟随及医疗服务安全需要独立实现和验证，不由当前静态VLN结果推导。论文的公开RGB协议不能偷偷加入部署时的真值位置或其他特权信息。
