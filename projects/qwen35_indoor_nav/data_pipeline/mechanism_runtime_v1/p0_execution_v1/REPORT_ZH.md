## 科学裁决

支持：自动元数据筛选、真实动作/碰撞留证、超时停止与跨场景调度确实能运行。

不支持：当前固定TV/sink/bed/dining-chair组合能覆盖多数场景；当前实现已可高效批量生成机制族；已有新方法正收益、泛化或CVPR竞争力。

仍未测试：对真正可构造的数据族，新监督是否优于强任务状态/事件集合/未来预测监督。4个元数据拒绝和1个资源截断不能回答这个算法问题。

论文定位与UAD/EgoCoT继承边界见 [论文范围说明](PAPER_SCOPE_CLARIFICATION_ZH.md)。统一VLN是最终模型目标，交叉续接记忆是待验证的主创新，不把静态模板的工程进展当成通用能力。
