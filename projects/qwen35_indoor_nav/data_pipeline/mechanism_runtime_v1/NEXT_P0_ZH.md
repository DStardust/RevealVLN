本交接不是 EXECUTION_AUTH，当前 runtime_allowed=false。主 agent 审核最终 P0 CPU 结果、完整 driver/依赖源码锁、解释器真实路径与哈希、旧 smoke PASS 和新 GPU2 租约后，才能另写不可覆盖的 EXECUTION_CONFIG/EXECUTION_AUTH。不要从草案直接运行。

P0 supervisor：`p0_driver_v1/supervisor.py --output <本目录下新的已准入批目录>`；只用既有项目内 stdlib Python 启动。子进程自行使用已验收 Habitat 环境。GPU2 必须重新确认空闲条件；若 GPU 状态变化，停在准入，不终止未知任务。

预算沿既有协议：五候选，总 6000 秒/200000 次动作；每候选发现 720 秒/20000 动作，首个完整 preflight 冻结后认证 480 秒/20000 动作。内容子预算 12 GiB，全目录停机高水位 14 GiB，绝对磁盘/RAM/GPU 上限 16/16/8 GiB。异常收尾预留不用于扩充内容。

当前 smoke 的 9 条轨迹含全部落盘/导出/读取合计约 424 秒；不能假定同等长度的 27 条认证会在 480 秒内完成。记录阶段实际耗时及预算截断，绝不能把 I/O 或时间额度耗尽说成机制不可行。若需要改变持久化实现或预算，先给版本化工程修订，不能静默更改既有动作预算、候选或科学阈值。
