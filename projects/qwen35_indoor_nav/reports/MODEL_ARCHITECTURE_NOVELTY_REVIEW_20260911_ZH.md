# 模型结构创新与论文故事：近邻核对及下一步

2026-09-11。响应本轮新增要求：模型侧也需要实质增量，避免与近邻同构，论文叙事必须由证据支持。本文件是有界研究审查，不改写 MAINLINE_FREEZE_V3，不授权直接把新结构并入正在恢复的普通训练。

## 1. 先明确当前事实

当前普通基座是 Qwen3.5-2B + LoRA + 四类动作头，输入为普通指令、近期图像与已执行动作。它还没有长期任务记忆，没有接入真实交叉续接监督。这是共同实验基础，不是目前已实现的模型创新。

教师版明确将“共享执行记忆 + 结果预测联合训练”写为拟开展方案。现有最扎实的新增产物在数据构造和严格核验侧。不能将修复多卡通信、加速、模型换底座或 STOP 指标提高计为架构贡献。

## 2. 本轮发现的直接重合点

不能只查 VLN；VLA、部分可观测控制和预测状态学习也有直接近邻。本轮使用 Undermind 做跨领域语义检索，再核对一手论文；通过 alphaXiv 读取 GMP 官方代码的相关结构，未安装或复现其他方法。

| 拟强调的操作 | 已有直接相关操作 | 本轮判断 |
| --- | --- | --- |
| 需要时才读取任务记忆 | GMP 用二值记忆门和历史交叉注意力，在有/无记忆的动作误差对照下校准门控 [1] | 泛化“何时读、读什么”不能作为原创 |
| 不改基座，增加轻量历史分支，并在动作端融合 | Remember Smarter 的视觉历史压缩器与动作端残差读出 [2] | “独立分支 + 残差”不足以形成结构创新 |
| 少量记忆 token 跨时间传递 | μVLA 的主干内循环记忆、TBPTT 及动作复制隔离 [3] | 增加记忆槽、长历史反传、因果掩码本身不新 |
| 记住机器人做过什么，以便处理失败与任务进展 | CAMP 用动作历史重建和压缩训练行为记忆 [4] | “记住已执行动作”已是直接研究对象 |
| 依据视觉证据选择并更新指令状态 | Instruction-as-State 的子句激活、视觉细化和门控回写 [5] | 换成“证据门控”称呼仍需逐算子比较 |
| 学习完成/剩余目标以及历史地标 | Dual-Anchoring 的进度与地标辅助监督 [6] | 不能把任务进度、历史回忆及辅助头本身说成首次 |
| 以未来实验结果区分过去 | PSR 的历史—未来检验表示；项目原 P1 已列为核心理论祖先 [7] | 续接预测不是新的理论原理 |

GMP 代码观察：`MemoryTransformerBlock.forward` 先计算 `history_cross_attn`，再由 `memory_gate_val` 二值/连续调制，残差加入当前特征；代码含 STE 版本。该处的条件计算跳过还有 TODO，不能因工程实现与论文表述存在细节差异，就宣称我们首次提出选择性记忆。

以上是对具体宽泛主张的否定，不是因为思想有共同祖先就否定全部研究方向。尚未全量复现这些方法，搜索也不能证明全球无重合。

## 3. 架构侧要补足什么

当前尚无通过近邻审查的新增结构。刚提出的“任务证据记忆分支 + 门控”保留为工程候选，但不批准作为原创贡献，也不直接投入方法长训。

优先研究一个更窄的问题：**如何让历史进入动作的通路，只保留并使用由真实后续结果证实有用的信息，同时避免把无关绕行写成任务变化？**

必须明确三个算子，而不是先给模块起名：

1. 写入：当前实际观察和执行反馈怎样改变长期状态？与普通循环更新、指令状态门控的数学差别是什么？
2. 读出：结果监督约束的那部分状态怎样直接影响动作，而不是只供训练用头读取、被策略忽略？
3. 约束：哪些真实对照要求信息保留，哪些要求特定输出稳定？有限续接结果一致不代表两段完整历史全局等价，不强制整个空间记忆相同。

下一版结构草案限两个候选，先比较再保留一个：

- 写入侧候选：由交叉执行可辨识的任务差异监督局部写入/保持，而不是仅由当前视觉相关性或下一动作误差决定。必须排除其只是“普通门控换标签”；若区别只在标签，应归类为监督算法，不冒称架构创新。
- 读出侧候选：将经结果检验的任务状态作为历史影响动作的明确瓶颈，使动作与结果读出共享有约束的访问接口。必须排除其能被普通线性层吸收、只是重参数化，或与已有预测状态/概念瓶颈策略同构；未完成这些检查前不准入。

两者均为研究候选，尚无优越性或原创性结论。不能为满足“有新架构”而堆更多模块，也不能以更换场景、主干、名称或损失权重替代实质差异。

## 4. 最小区分实验

保持同一初始化、普通与特殊轨迹池、输入、记忆容量、合法动作标签和训练计算量，做结构与监督的交叉对照：

|  | 仅动作/强任务状态监督 | 真实交叉续接监督 |
| --- | --- | --- |
| 标准循环/门控记忆 | 强基础对照 | 识别新增监督的作用 |
| 待审新结构 | 识别单独结构的作用 | 检验二者联合及交互作用 |

还需要同池动作监督、常规未来预测以及去交叉关系的对照，延续 V3 的原否证条件。不能只比较“新模型 + 更多数据”与“旧模型 + 少量数据”。

机制验收先检查：当前窗口完全相同时，交换经过核验的任务记忆是否按预期改变后续决策；交换无关历史是否不引入错误变化；未来查询是否能泄漏进入记忆/动作；早期关键事件是否得到有效梯度。不是所有样本都应立即产生不同首动作，应按真正的决策分叉位置检查。

最终结局仍是未见房屋完整任务满足、恢复能力、普通导航是否退化及资源成本，而非仅报告记忆探针准确率。若同数据强任务状态监督已经不劣，或新结构没有独立收益，应否定对应模型贡献，保留失败。

当前特殊数据仍主要为一个顺序可见事件程序，强任务状态解释可能已足够。扩展真实任务程序与房屋覆盖是外推检验需要，但不能为了让基线失败而人为改变协议或削弱其监督。

## 5. 给老师讲的故事应怎样调整

建议现阶段表述：

> 面向需要连续完成多个移动步骤的居家服务，我们研究机器人怎样把已经发生的关键经历保留为可用于行动的任务记忆。研究一方面构造可真实重放的执行对照，用后续任务结果识别哪些历史有用；另一方面探索与这种监督相匹配的记忆结构，使保留下来的信息真正参与导航决策。当前已完成普通基座和受控数据的工程准备，模型结构的具体增量及其收益将通过与已有记忆和任务状态方法的匹配实验确定。

完整故事是“具体执行困难 → 现有方法的可测不足 → 非同构的小结构/训练算子 → 对照数据为何能监督它 → 独立闭环证据”，不是“养老机器人需要记忆 → 加记忆模块 → 宣称创新”。

EgoCoT-Bench 的联系仍是从可核验的时空证据走向证据支持的行动；不声称其没有记忆，也不复用测试答案。到达房间、看见物体、完成照护操作保持不同语义。

教师稿可说明研究假设与当前进度，但暂不写“提出了全新架构”“首次学会任务记忆”“创新已验证”。结构完成近邻审查后，再将精确模块、信息流图和实验问题纳入正式稿。
